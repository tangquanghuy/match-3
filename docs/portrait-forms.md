# 立绘形态标注与四维筛选

2026-10-19 首轮归类。范围是现有 1800 张部队 WebP；不包含异界部队或主角武器图。1800 张均查看了成图缩略图，另对原标为类人的 518 项专项复查，累计 90 张另行放大复核。当前是粗粒度形态索引，可继续按清晰成图修订边界项；没有宣称逐张检查所有绘画细节。

## 五类判定口径

| 形态 | 判定 |
| --- | --- |
| 人形 | 人脸与人形身体。兽耳、尾巴、角、肤色、翅膀不使其变为类人；矮小或高大也不直接改变类别。 |
| 野兽 | 以可辨认的动物躯体为主体，包括鸟、鱼、虫等；体型、材质、附带特效不直接改变类别。 |
| 类人 | 身体接近人形，面部明确为兽面、骷髅或其他非人面孔。**人脸角色不归类人。** |
| 怪物 | 明显复合或非常规生物躯体，例如人上身接马身、鱼尾或蛛身，以及龙体。 |
| 异形体 | 缺少常规人或动物躯干，例如软泥、游离形体、眼球团和主要呈现为器物的活化体。 |

先看主体整体：人面蛛身仍是怪物；正常骑乘坐骑的人物按骑手判断，融合为一体的人马按怪物判断。人形和类人的区别看实际面部，不能从原种族名推断。遮脸、戴头盔不是非人面孔的证据；人形雕像保留人形轮廓，不能只因材质而归异形体。怪物与异形体的边界看是否有稳定可辨认的生物躯体。

提示词只作离线来源证据：例如“狼族、狐族”可能画出人脸角色。`Troop_K16_02`（6115 游侠）、`Troop_K16_17`（6807 狐人恶汉）均按成图归人形。不能把源名称、服装和器具拆成 AI 的外观标签。

本次专项复查将 45 项从类人改为人形，包括兽耳人脸、保留人脸的亡灵外观、普通遮脸角色等；另外纠正了 4 项龙体或复合躯体为怪物、1 项游离眼球为异形体。类人必须有明确的非人面孔，不能因为源种族、灰绿肤色或身体材质而判定。

## 四个筛选维度

| 字段 | 来源 | 匹配方式 |
| --- | --- | --- |
| manaColors | 原部队 `manaColors` | 完整颜色集合相等，顺序无关；单红不等于红蓝 |
| rank | 原部队 `rarityIdx`，按下表映射 | 五档精确匹配 |
| form | 本次成图归类 | 五类精确匹配 |
| role | 原部队 `role` | 复用项目现有九类，不从图片重新猜职责 |

| 当前显示稀有度 | 数据键 / rarityIdx | 通用稀有度 | 数量 |
| --- | --- | --- | ---: |
| 普通、精良 | Common / 0；Uncommon / 1 | 杂兵 | 362 |
| 稀有 | Rare / 2 | 精锐 | 357 |
| 传说 | UltraRare / 3 | 首领 | 596 |
| 史诗 | Epic / 4 | 领主 | 252 |
| 神话 | Legendary / 5 | 传奇 | 233 |

注意当前项目的 `Legendary` 显示为神话，`UltraRare` 显示为传说，不能按英文直译映射。普通和精良在当前五档方案中合为杂兵。

职责沿用 [roles.ts](../src/meta/data/roles.ts)：坦克 Defender、输出 Striker、供魔 Generator、辅助 Support、法师 Mage、术士 Warlock、刺客 Assassin、战士 Warrior、统帅 Warmaster。这里登记的是现有定位标签；后续生成技能时仍须检查实际效果是否符合定位。

## 数据与工具

- [portrait-forms.json](../data/portrait-forms.json)：每个图片文件一条形态、内容哈希、查看状态和依据，同时保留提示词名称与原始主体文本作为离线证据。
- [portrait-forms.mjs](../scripts/portrait-forms.mjs)：读取现有部队数据，派生四维索引、精确查图、列出可用组合并校验图片。
- [build-portrait-forms.mjs](../scripts/build-portrait-forms.mjs)：刷新外部提示词关联，保留内容未变图片的视觉标注。新增或内容变化的图片标为待归类，不按原种族名自动分配形态。

```powershell
node scripts/portrait-forms.mjs check
node scripts/portrait-forms.mjs stats
node scripts/portrait-forms.mjs availability
node scripts/portrait-forms.mjs query 人形 首领 坦克 Blue,Purple
node scripts/build-portrait-forms.mjs D:/Code/dnf/comfyui_batch/立绘提示词汇总.txt
```

运行筛选只需要仓库数据和现有图片，不需要外部提示词文件。中文颜色“红、蓝、绿、黄、紫、棕”和英文颜色键均可用于命令查询。

当前记录统计：人形 803、野兽 197、类人 468、怪物 243、异形体 89。1800 个文件按内容哈希对应 1794 张不同图片；同内容图片的形态一致。共图只共享视觉分类，颜色、稀有度、职责仍沿用各源部队数据，筛选后再对相同内容去重；不合并部队身份或魂片进度。

现有 42 种颜色集合形成 **1092 个非空四维组合**。四维不能任意交叉后假定都有图片。`availability` 仅导出有图组合及数量，不导出原名称、种族、王国和提示词；后续运行时菜单应按已选项逐步收窄到有图选项。精确查询无候选返回 `no_exact_match`，不暗中放宽颜色、稀有度、形态或职责。
