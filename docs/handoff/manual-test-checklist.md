## 2. AI 出战斗块

用真实剧情试这几种场景：只是发现敌人或对峙、潜行、主动开战、被偷袭、精锐带杂兵、首领、3 个以上同类敌人。

- [ ] 对峙或潜行时不出块，真正交战时才出块。结论：
- [ ] 每个敌人只有七项：`name/race/rank/level/form/role/manaColors`。姓名、种族与正文一致，符合当前世界观。结论：
- [ ] 正文不再用“E1、E2…”标注敌人（2026-10-30 已从提示词删除），敌人身份自然写在剧情里。结论：
- [ ] 输出块后 AI 停下，不预演战斗、不扣血、不判胜负。结论：
- [ ] 3 个以上同类敌人时，没有完全相同的"克隆"配置。结论：

## 3. 入口卡与进入战斗

- [ ] 战斗块显示为入口卡，按钮是"进入战斗"，没有多余的说明文字或面板。结论：
- [ ] 点击后直接进入原生加载页，再进入战场，中间不弹队伍准备面板。结论：
- [ ] 敌人详情里的姓名、种族、等级正确。技能说明是中文，数值已算好，没有 `max(...)` 这类公式或编码。结论：
- [ ] 敌人立绘的形态符合块里的 `form`。结论：
- [ ] 入口是正文后的紧凑横条：我方/敌方缩略图、VS、右侧按钮。新聊天第一次渲染就有缩略图。缩略图下面不再列敌人姓名；鼠标悬停缩略图显示“姓名（阶级 Lv.N）”。结论：

### 3.1 同一楼反复测试（临时功能）

1. 打完一场、战报和 AI 回复都发出后，先在酒馆里删掉战报消息和 AI 回复，让战斗所在楼层成为最新一楼。

## 6. 战报与 AI 续写（本轮重点）

- [ ] 在结算页点"继续"后，聊天框自动以玩家身份发出一条以 **【三消战报】** 开头的消息。结论：
- [ ] 战报内容逐项对照实际战斗：胜负和回合数、每个敌人被击败或剩余生命、我方每人生命变化和是否倒下；战报不含魂片、学会能力等三消养成内容（这些只在结算页显示）。结论：
- [ ] AI 按色色卡原有规则自行结算战利品和经验（这部分不在三消结算页显示，属正常）；AI 没有把魂片写进背包，没有把未上阵的同伴写成参战。结论：
- [ ] 战报里没有 battleId、`/人物`、`enemy-1` 这类内部标识。结论：
- [ ] AI 续写与战报一致：没有改胜负，没有补造招式或奖励。结论：
- [ ] MVU 中人物的 `当前生命值` 按比例回写，`三消战果` 多了一条记录。结论：
- [ ] 再点入口卡的"查看本场战果"，只是重新打开旧结算。点继续不会再发一次战报，也不会重复发奖。结论：
- [ ] 战报发出、AI 回复之后，旧入口卡显示"查看本场战果"，不报错。结论：

## 7. 放弃战斗

- [ ] **战斗中放弃**：在战斗设置里点"放弃本局"。应按败北结算，点继续后发出战报。结论：
- [ ] **中途关掉页面后放弃**：打开底栏"三消"→"存档"→"待完成的剧情战斗"，点"放弃战斗"再确认。结论：
  - 应弹出败北结算页。
  - 点继续后发出战报，内容写"我方放弃战斗，按败北结算"。
  - 生命不变，`三消战果` 多一条记录。
- [ ] 放弃后 AI 能正常续写，剧情不会卡在等待战报。结论：

- [ ] 结算页还没点"继续"时重新渲染消息，结算页应保留，直到点继续发出战报。结论：

## 9. 底栏管理页

- [ ] 编队、魂片收藏、往昔再现、战斗记录、存档五个分页都能打开，风格与原三消一致。结论：
- [ ] 战斗记录按对手分组；再现只列学会能力的场次和最近一场，没有“显示全部”。点开一场只显示“胜利/败北 · N 回合”和实际奖励缩略图，不显示结算大图。结论：
- [ ] 魂片收藏点卡片翻到“可学会能力”，说明较长时能滚动，点背面翻回。结论：
- [ ] 编队：能编入同行同伴（`同行誓约=true`）、调整顺序、移出。不需要手选颜色或基础技能。结论：
- [ ] "装配已学能力"只列出已学会的能力，不受颜色限制。没有已学能力时显示提示文字。结论：
- [ ] 主色有主手武器时，编队页显示“主手武器（装备名）：骑士之剑（默认）”和“更换武器”按钮。打开的选择窗口能搜索（中文输入法正常）、按稀有度/类型/法力色/拥有状态筛选，详情里有技能说明。结论：
- [ ] 普通、精良、稀有武器可直接登记；传说/史诗/神话/末日显示价格（60 万/120 万/200 万/300 万通用币）。购买要再点一次确认；钱不够时按钮不可点；剧情战斗未结算时不能买。买后 `人物.背包.通用币` 减少，`三消已购武器` 多一项。结论：
- [ ] 重新生成购买所在楼层后，钱和购买记录一起回退，编队页显示“（未购买，出战使用骑士之剑）”。结论：
- [ ] 在变量管理器里手改 `人物.背包.通用币`，约 2 秒内被改回，没有弹窗。改完不等 2 秒直接发消息，AI 读到的仍是原来的数。结论：
- [ ] 看到残留的技术文字（原始聊天 ID、英文颜色、内部代码等）时截图。结论：

## 已知限制（不用报）

- 数值未平衡：敌我强弱和战斗时长都不准。2026-10-28 联调那局，20 级主色配 1d4 武器面板，打两头狼 26 回合后败北。
- 正文入口横条上有“重置本场（测试）”按钮，是临时测试功能，上线前会去掉。
- 色色有临时 HP 时不能开剧情战斗。
- 战斗中途刷新会从开局重来，可以借此重打。
- 同伴稀有度：色色卡没有现成字段。现在读可选的 `三消.稀有度`，没有就取已穿戴装备的最高品质。稀有度决定颜色数量：普通、精良 1 色，稀有到史诗 2 色，神话 3 色。颜色首次写入变量后不再变化。
- 淬炼与材料还没做，剧情胜利只发魂片。
- 默认队伍只有主色，同伴要先在编队页编入。
- 控制台里有一批 `127.0.0.1:8000/assets/*.js` 的 404。这些是模块预加载提示的地址拼错了，不影响功能。
