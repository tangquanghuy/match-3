# 页面信息层级与视觉复查 · 2026-09-25

## 本轮范围

只调整愿望单、活动、活动兑换及宝箱愿望单入口的展示和操作流程。抽卡概率、保底、宝石经济与每周刷新机制保持原样。

- 愿望单分为选择角色、已选角色、召唤规则；复用图鉴卡面与筛选逻辑，完整筛选收进弹层。
- 选择页去掉常驻配额、概率和经济预测。触及上限时提示并保留原名单。
- 活动出战页保留本轮状态、战术与出战操作，规则及奖励进入次级页面。
- 兑换货架保留商品、数量、库存、价格和兑换操作；用途和持有明细放进商品详情。
- 桌面兑换页签按内容宽度排布；手机使用活动选择器。内容纵向滚动，不强行压进一屏。

## 真实页面截图复查

截图来自本地 Vite 页面和 Playwright Chromium。自动检查只作为回归保护，视觉复查另看真实截图。

检查了留白、信息密度、按钮比例、文字换行、颜色对比、首屏操作，以及展开后的页面：

- 愿望单：1600、1280、768、390、320 宽度；空名单、单选、27 人名单、追寻、筛选与规则。
- 活动：桌面、平板、手机的总览与六种玩法；规则与奖励次级页面。
- 兑换：桌面、平板、手机的六家货架，以及商品详情弹层。
- 宝箱：有 27 名愿望角色时的入口，避免空名单短文字掩盖布局问题。

看图后修正的具体问题：

1. 1280 × 720 愿望单首排加入按钮露出不足：减少短屏标题区冗余与卡面高度，保留按钮高度。
2. 阵营突袭重复编队操作导致手机出战按钮下沉：移除重复入口并重新安排战术卡。
3. 手机活动总览继承固定行高，卡片出现额外空白：恢复内容驱动高度。
4. 商品详情继承浅色主题文字：修正深色弹层文字，并增加 4.5:1 对比度检查。
5. 宝箱愿望单入口在手机上折成多行：重新安排操作区，保持完整单行入口。
