# 竞技场场间调整站位

## 根因

`fighting` 是整届竞技场进入连战后的阶段，结算一场后仍然保持该值，并不表示当下有一场战斗尚未结算。界面在连战阶段仍显示站位按钮，但 `arrangeArenaTeam` 原本只接受 `building`，因此首场之后调整会报阶段错误。不是客户端/服务端版本差异。

## 修复

- `building` 与 `fighting` 均可重排已选四张卡，不改变选牌、胜负、奖励或竞技场阶段。
- 单场是否进行中检查权威 `pendingBattle`；竞技场票据未结算时拒绝调整，不作废票据。
- 保留卡数、重复卡和非本届卡校验；未报名/选牌未完成返回正常业务错误。
- 保存站位期间禁用重复调整、开战及弃赛；首场准备期间同样防重复点击。
- 失败时从网关存档恢复显示，不保留仅在界面生效的假站位；网络异常先只读同步，既不自动重放调整也不清除战斗票。页面卸载后忽略迟到的界面更新。
