# 火枪手与共享反射/选敌规则复核

## 证据与范围

- 部队 `6004`、技能 `7004`：仓库英文快照仅一条 `M+2` 指定敌人伤害；native为一条 `Damage / FromTarget`，费用6、红色。
- 隐匿依据：`data/raw/troops.gow.en.json` 的英文 Stealthy 特质描述。存在其他可选目标时隐匿排除；全部剩余目标隐匿时允许选择。
- 眩晕依据：官方状态页快照 `artifacts/gow-skill-audit/gold-primary-sources/official-status-effects.html`，Stun关闭特质。因此Stealthy特质受眩晕影响。
- 反射依据：官方开发者Sirrian发布的4.5补丁（2019-08-28），新保存完整原帖到 `artifacts/gow-skill-audit/gold-primary-sources/official-reflect-4-5.json`。第一楼明示向下取整、最低1点、仅敌方伤害触发、友方和状态伤害不触发，以及反射作为特殊伤害不受Armored/Spell Armor特质减伤。
- 来源地址记录在快照来源清单；该历史公告不声称是2026年官方实时完整规则。
- 取消/过期/错误阵营选敌属于项目的行动输入原子性：未选定合法目标不提交施法。它不是依据GoW客户端实测得出的隐藏机制。

## 本次已修复

1. `reflectDamageAmount` 由四舍五入改为向下取整；13点伤害反射6点，而不是7点。技能及骷髅路径共享该函数。
2. 技能伤害显式传入伤害来源阵营，友方/自伤不触发或消耗Reflect；同时覆盖普通、群攻、散射、溅射、分割、随机波次。特质伤害与吞噬伤害口也传递来源阵营。
3. `isUntargetable`不再让眩晕中的Stealthy特质生效。
4. 手动指定目标在扣蓝、写行动日志、清附魔、施法触发特质前校验；取消、过期、友方或被隐匿排除的目标不提交施法。失败选择恢复选择器消耗的RNG。
5. `enemyChosenAndBelow`候选列表与实际目标选择的隐匿条件一致，避免列表给出一个实际执行会过滤的主目标。
6. 修复反射伤害对来源角色的屏障判断：依据官方4.5公告“反射为特殊伤害，特质减伤不生效”和官方状态页“屏障抵挡一次伤害”的**规则组合推论**，来源角色的屏障吸收反射并消失，反射本身仍在受击者处消耗；法术与骷髅共用此口径，不让反射互相递归触发。被魅惑的队首攻击己方时，依据4.5公告“友方伤害不触发反射”，骷髅路径现在也跳过己方反射。尚未将施法者/受击者双方致死、复活替补顺序签收。
