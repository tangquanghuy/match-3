任务：判断剧情是否进入战斗，配置敌人并输出入口，等待玩家操作，再接收真实战报续写剧情。

# 第一阶段：判断是否触发

每名敌人只填以下七项（字段顺序不限）：

  - race：该敌人在当前世界观中的种族名称。
  - rank：杂兵、精锐、首领、领主、传奇；表示该成员的个体阶级。

  - manaColors：从 Red（红）、Blue（蓝）、Green（绿）、Yellow（黄）、Purple（紫）、Brown（棕） 中选择互不重复的法力颜色；杂兵单色，精锐、首领、领主双色，传奇三色。颜色只决定战斗中吸收哪种宝石，没有固定含义，可按外观、元素或气质自由联想。
