# 周活动重做：玩法、奖励与页面（2026-09-25）

## 实施范围

六活动常驻，每周一当地时间00:00统一刷新进度、奖励领取状态、活动印记、首领和登塔状态。商店库存独立按当地时间每两天零点刷新，不随周一额外补货。钱包中已经到账的宝石、材料、角色及养成保留。无需清档。

本版实现两种战术选择、不同跨局状态与奖励条件；不是完整分支地图、随机遗物或新战斗引擎。六活动仍共用三消战斗与现有编队。

入口：`game.html#events`；奖励页 `#events/<typeId>/rewards`；商店 `#shop/<typeId>`。

## 宝石预算

| 来源 | 周上限 | 领取方式 |
|---|---:|---|
| 六个独立活动 | 600 × 6 = 3,600 | 里程碑达标后战斗结算自动入账 |
| 每周远征共享目标 | 1,800 | 任意活动累计6/12/20/30胜，分别300/400/500/600 |
| 入侵守土大赏 | 80 | 完成三条防线20宝石，最多4次 |
| **活动直接宝石合计** | **5,480** | 正常完整周预算 |

相对旧表430的配置预算约12.74倍；旧版还存在部分里程碑货币未实际入账的问题，本次一并修复。这里比较的是配置值，不是旧玩家实测收益。活动外的每日首胜、战斗内收集、首通、竞技场等未包含在5,480里。

- 常规积分里程碑：100 / 240 / 420 / 650 / 900 / 1,200。
- 世界事件物资里程碑：6 / 15 / 27 / 42 / 60 / 84。
- 对应宝石：150 / 150 / 150 / 75 / 75 / 0。前三档450，占单活动宝石75%；最后一档偏材料追求。
- 共享目标不要求每个活动都参加：专玩一个活动也能完成30胜。素材种类与总量沿用原表，不随宝石放大。
- 单活动普通路线通常5胜达到前三档、9胜拿满宝石、12胜拿满材料轨；世界和试炼按各自条件另算，首领战的胜场成本也更高。
- 奖励是周常预算，不是每日要求；无新增体力、付费门票或抽卡概率暗调。

单一配置源：`src/meta/data/events.ts` 的 `EVENT_WEEKLY_RULES`、`EVENT_SHARED_GOALS`、`EVENT_DEFENSE_REWARD`。`EVENT_WEEKLY_GEM_CAP` 从奖励表推导，页面与测试共用。

## 六种玩法

| 活动 | 跨局机制 | 战术差异 |
|---|---|---|
| 入侵 | 三条防线，胜利推进、失守退回第一条；整轮完成后难度缓升 | 稳守全队护甲+8；突围敌人等级+3、胜利120分（通常100分） |
| 突袭首领 | 同周同阶固定首领及护卫，首领真实生命跨场保留，战败也累计净生命损耗 | 集中讨伐维持输出；防护护甲+12、攻击-20% |
| 末日之塔 | 25层，每5层首领；锁定本轮阵容/站位，残血和阵亡延续 | 继续攀爬；6/11/16/21层可休整，存活成员恢复35%上限生命，本场积分50 |
| 阵营突袭 | 补给站→城门→堡垒，第三节点首领；目标王国每名角色全队攻击+2、生命+10 | 迂回胜利使下一据点敌方护甲减半；强攻敌人等级+4、胜利120分 |
| 世界事件 | 收集物资推进奖励，匹配当周种族每名多1物资 | 搜寻6～8物资；护送敌人等级+5、10～12物资 |
| 职业试炼 | 主角和已解锁、已装备职业必需；连胜倍率1/1.3/1.6/2，失败清零 | 研习职业经验×2；考验敌人等级+5，主角存活获胜再加25%积分（封顶240）、职业经验×3 |

### 首领与专精

- 首领血池为该首领基础生命×6×1.15^(阶层−1)，受战斗生命上限9,999约束；这是生命预算，不代表固定需要6场。
- 护卫伤害不进入首领血池；只保留本场首领开战至结算的净生命损耗，不将治疗前总伤害重复计入。
- 以半血或以下开始下一战时，首领攻击提高30%。本版不是战斗中即时半血变身。
- 已解锁屠神/破城专精分别作用明确标记的活动首领/入侵目标，骷髅和法术伤害均接通，普通战斗不受影响，昏迷时停用。
- 专精倍率依当前品质0～5（基础品质+晋升，封顶5）从3倍到5倍插值；不是把最高仅3阶段的晋升数误当5阶段。

### 登塔约束与修复

- 等级从5级按每层+2独立增长；轮转王国只决定敌人风格，不叠加王国序号难度。
- 当前生命独立于最大生命传入战斗，残血不再被误当新的最大生命。
- 保留原始整队的存活/阵亡记录，三层以上也不丢失已阵亡角色；召唤物不成为跨层资产。
- 营地重复预览不叠加治疗，阵亡成员不复活。
- 战败、主动放弃、全灭或25层通关结束本轮。收尾时只奖励超过本周已付楼层的新高：每层2荣耀、每5层1符卷，合计最多50荣耀和5符卷（里程碑之外）。
- 取消旧“最多6程”的实际奖励限制；旧 `playRewards` 塔计数仅保留兼容诊断。

## 商店与材料预算

- 每活动每周最多赚360印记，消费不恢复赚取额度。正常每100分10印记，试炼高连胜至多24/胜。
- 原无限材料条目新增每期库存，一般12次，塔钢锭10次；原有限货架维持自己的库存数量。每期两天，补货不消耗印记；精选角色按期轮换，具体规则见 `event-shop-two-day-refresh.md`。
- 每店新增低价值余印兑换：10印记→150黄金，独立小条目，不挤占主货架布局；总消费仍受周印记供给约束。
- 印记不足时“去出战”先回活动页选战术，不直接开战；赚取额度已满时显示周上限，不再误导继续刷币。
- 宝石显著增加不代表钢锭、符卷等同时无限膨胀。守土和首领额外材料各最多4次/周，塔用新高楼层预算。

## 页面与操作

- 总览加入共享远征目标、各活动剩余可获取宝石、统一刷新提示。
- 详情先展示本活动状态，再展示战术与出战；首领有真实血量比例，塔显示存活人数/营地/本周纪录。
- 保留奖励独立页、兑换入口；提供编队、职业设置快捷入口，出战条件缺失给具体修复指引。
- 复用持有图鉴的筛选与检索：`#troop/filter/kingdom/<编码王国>`、`#troop/filter/race/<编码种族>`，链接打开时清除冲突过滤并定位目标范围。
- 手机详情压缩装饰图、使用活动选择菜单；主操作不横向溢出。桌面商店保留主推+紧凑货架，余印和预算放底部。

## 存档与结算

- `revision=2` 区分新奖励账本。旧档保留已领材料、购买记录与进度，只补同一宝石档位差额，下一次相应活动结算入账。
- 旧世界事件曾发80宝石的档位现在75，保留已发金额；该升级周最多因此比正常总预算多5宝石，不回扣。
- 旧塔最高层初始化为已付楼层，避免旧高层重新领奖。
- 每场战斗ID持久记录结算标记；重放和读档后重复提交不再发钱、加经验、累计胜场或扣首领血量。
- 上周在途战斗在跨周后不回拨进度、不补发其战斗收益，结算页提示周活动已结束。
- 失败出战请求回滚临时首领/塔状态；零存活、非营地休整在网关拦截。
- 修复里程碑/商店货币对象含 `undefined` 导致钱包校验拒收的问题：可选货币以0补齐；测试检查实际钱包，不只检查结算文字。

## 抽卡联动模型

运行：

```sh
npm run economy:gacha -- weeklyLight
npm run economy:gacha -- weeklyStandard
npm run economy:gacha -- weeklyFull
npm run economy:gacha -- docs/events-budget.example.json
```

| 情景 | 活动胜场与条件 | 活动宝石 | 持续净宝石/周 | 抽数/周 | 活动分钟 |
|---|---|---:|---:|---:|---:|
| 轻度 | 入侵6、阵营6，守土2次 | 1,640 | 1,854 | 12.36 | 42 |
| 标准 | 入侵9、阵营9、世界9（2名种族加成）、试炼3连胜，守土3次 | 3,960 | 4,514 | 30.09 | 108 |
| 满宝石 | 入侵12、首领9、塔9、阵营9、世界10、风险试炼6连胜，守土4次 | 5,480 | 6,034 | 40.23 | 243 |

- 标准/满额：首胜350 + 竞技场504 − 报名费300，再加活动；轻度首胜150、竞技场64，无报名费。
- 时间额外包含情景里显式填写的败场，默认3分钟/场、首领5分钟/场；不含加载、编队、消费、其他玩法。胜率和完成难度尚待实测。
- 世界事件采用掉落均值，临界档位存在随机偏差；风险试炼按主角存活计算。
- 满宝石不等于六活动内容通关：塔9胜即可达600宝石，25层仍有材料与挑战目标。
- 表格按净预算100%抽卡，未计王国首通、寻宝、入侵赛季、一次性库存与其他消费。可在JSON里改分配比例、路线和场次重算。
- 标准情景指定首个神话追寻平均付费预算约45.55天、上限约46.52天；后续平均约89.13天。满额首次上限约34.80天。都是预算等价换算，不是玩家真实达成保证。
- 本次保留150/抽、品质概率、愿望份额、200/400追寻和十连稀有保底。王国首通100/200/300仍为有限奖励池，与周收入分开建模。
