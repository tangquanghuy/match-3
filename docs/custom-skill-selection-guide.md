# 自设技能选型图鉴

**你的角色靠什么赢下战斗？**

是集中火力击倒一个敌人，制造宝石带动全队，保护队友，还是用吞噬、变形、复制等特殊能力改变战局？这份图鉴供你挑选自设角色的主动技能方向。

选型时可以先确定 **一个核心效果**，再搭配 **一个辅助效果**；如果希望技能更有个性，再加入触发条件或代价。表中的现有部队用于参考技能构思，不要求整套照搬。伤害、数量、概率与法力消耗可在确定玩法后再商定。

> 表格中的“—”表示该稀有度暂未列出对应参考。少见能力也可能出现在较低稀有度部队身上。

## 先选你想要的战斗风格

| 我想让角色…… | 可以优先看 |
|---|---|
| 一击重创关键敌人 | 单体伤害、真实伤害、斩杀、击杀奖励 |
| 一次压低整支敌队的血线 | 全体伤害、溅射、持续伤害 |
| 带动全队连续施法 | 造石、转色、爆破、灌蓝、额外回合 |
| 在前排越打越强 | 加攻击、加护甲、吸血、属性窃取 |
| 保护队友、稳定战局 | 治疗、屏障、赐福、净化 |
| 让对手的技能和阵容失去节奏 | 耗蓝、沉默、织网、驱散、站位调整 |
| 拥有鲜明的特殊能力 | 召唤、复制、变形、吞噬、献祭、自复活 |
| 玩随机性、交易与风险 | 随机分支、随机状态、金币消耗、概率效果 |

## 一、伤害：决定你怎样击倒敌人

| 可选类型 | 效果与玩法 | 传说参考 | 史诗参考 | 神话参考 |
|---|---|---|---|---|
| **单体／多目标打击** | 集中攻击一个目标，或分别攻击数名目标。适合刺客、射手、战士。 | 费里特·背后一刀 | 俄里翁·狂野狩猎团 | 战斗之神·冲突不休 |
| **全体伤害** | 同时打击所有敌人，适合群攻法师与压血线。 | 亚特兰大·箭雨 | 盘丝魔蛛·盘丝毒液 | 德拉古力斯·吸血鬼之刃 |
| **溅射伤害** | 攻击主目标时波及其他敌人，适合炮击、冲撞、连锁攻击。 | 石像鬼·岩石炮火 | 西勒诺斯国王·先砍后烧 | 红牛凯崔斯·血之饥渴 |
| **真实伤害** | 绕过护甲直接伤害生命，适合穿透、诅咒、精准刺杀。 | 坦克机器人-2000·齿轮重击 | 维诺克西亚·有毒气体 | 乔纳·风暴之盾·雷霆标枪 |
| **分摊伤害** | 把一份总伤害分给多个敌人，可偏向稳定均分或随机分配。 | 两栖机器人·伸缩舌 | — | — |
| **吸血** | 伤害敌人的同时恢复自身生命，适合吸血鬼、掠夺者、持续作战角色。 | 萨菲拉夫人·盗血窃命 | 鬼后·怨灵之歌 | 德拉古力斯·吸血鬼之刃 |
| **斩杀** | 以条件或概率直接消灭目标，适合处刑、暗杀和终结技。 | P4-NTH4·沉默齿轮 | 龙型-1337·分崩离析 | 天蝎王·皇室剧毒 |

**还可以选择攻击谁：**前排、后排、指定敌人、随机敌人、最虚弱的敌人、生命最多的敌人，或多名敌人。相同的伤害效果，配上不同选敌方式，角色的用途也会不同。

### 正面状态怎么选

| 状态 | 你想要的能力 |
|---|---|
| **屏障** | 替目标挡下一次伤害。适合护盾、守护与关键救援。 |
| **附魔** | 持续补充法力。适合为后续施法蓄力。 |
| **赐福** | 清理负面状态并提供状态保护。适合圣洁、祝福、庇护主题。 |
| **激怒** | 强化骷髅进攻。适合狂战士、野兽和近战爆发。 |
| **反射** | 受到伤害时反击伤害来源。适合镜面、荆棘与反制主题。 |
| **下潜** | 降低被指定技能锁定的风险。适合潜行、水下、隐匿主题。 |

> 治疗以恢复生命为主；若构思是“永久增加生命上限”，请在自设说明中单独提出。

| 状态 | 适合怎样的自设能力 |
|---|---|

| **沉默** | 压制敌人施法，适合封印、禁言与反法师。 |
| **冻结** | 限制敌人行动，适合冰霜、时间停滞与迟滞。 |
| **眩晕** | 干扰敌人行动与特质，适合重击、震荡与冲击。 |
| **缠绕** | 限制攻击，适合藤蔓、锁链、蛛丝与拘束。 |
| **织网** | 压低魔力发挥，让技能失去魔力加成。适合专门压制法师。 |
| **疾病** | 妨碍敌人补充资源与维持状态，适合瘟疫与衰弱。 |
| **诅咒** | 破除正面保护，为后续负面状态创造机会。 |
| **猎人标记** | 标记猎物，为骷髅追击提供联动。 |
| **妖火** | 让目标更容易承受法术伤害，适合法师队的前置辅助。 |
| **魅惑** | 让敌人的攻击转向其队友，适合幻术、诱惑与精神操纵。 |
| **恐怖** | 以恐惧打乱敌人站位，适合威慑、梦魇与恐惧化身。 |
| **死亡标记** | 给目标挂上概率死亡威胁，适合死神、诅咒与迟来的处刑。 |
| **狼化** | 让目标后续发生随机野兽变形，适合月亮、兽化与异变。 |
