# 王国探索：12 档与材料名称修正

## 已实现规则

- 12 档，每轮固定 4 场遭遇战、1 场首领、1 场最终首领；按本项目需求省去 Mythstones 门槛。
- 默认开放 1、2 档；打败当前最高档首领后，全王国开放下一档。本轮开始后锁定难度。
- 遭遇战失败保留当前场次、种子及阵容；首领失败结束本轮；放弃保留已获奖励。
- 最终首领固定掉落 1 颗王国对应的秘法属性石；12 档首领额外固定掉落 1 颗。
- 常规掉落、下一特质配方缺口补给保留；初级石基础掉落为六色均匀随机。
- 仅最终首领结算本档首通。1–3 档首次通轮 200 宝石、4–6 档 300；7–12 档记录通关但不新增首通宝石。已通关档位可重复挑战。
- 探索票据绑定 runId/tier/stage；同场失败重试保留阵容种子，但生成不同票据 ID，避免与已消费票据冲突。

## 数值证据边界

当前等级表：11、18、21、30、40、50、60、80、100、110、130、150。
1–5 档来自已保存的官方帮助截图；6 档 50 级、12 档 150 级及 12 档首领秘法掉落来自此前调研记录。
7–11 档仍待逐档核实，属于本项目当前配置，不应对外声称整张表逐项复刻官方。
敌人属性沿用项目 `enemyStatsAtLevel`，20 级以上按现有线性外推；不是已考证的 GoW 原始 NPC 公式。
低于 12 档的首领额外秘法概率未获得可靠逐档表，本轮没有擅自填写。

## 中文命名：直接对照本地原始数据

`data/raw/troops.gow.zh.json` 中 `stats.traits[].traitstones` 同时带材料 ID 与中文名称：

- ID 0–5：初级档，项目保留既有「初级…之石」。
- ID 6–11：高级档，项目保留既有「高级…之石」。
- ID 12–17：符文档，项目保留既有「符文…之石」。
- ID 18–38：秘法档共 21 种；修正此前将颜色机械拼为「奥术水·土之石」的做法，逐项使用原始中文名称。
- ID 39：项目保留既有「圣辉石」。

例如 `arcane:blue:brown` / ID 23 → 秘法护盾属性石；`arcane:blue:blue` / ID 18 → 秘法坚毅属性石。
高级魔法之石之后的符文魔法之石是独立档位，和秘法材料没有合并。库存键、数量、配方都保持原状。
命名单源为 `stoneName`，背包、特质消耗、奖励、宝箱详情统一使用；背包和宝箱档位标签改为「秘法」。

## 难度页第二版

移除 12 张大方块，使用王国背景、单档徽章、左右切换和紧凑 12 档刻度。
刻度使用原生 range 控件，可拖动、触摸、键盘方向键和 Home/End 操作，保存后恢复焦点。
未解锁区域灰显，滑块和按钮都只接受已解锁档位；本轮进行中禁用全部难度控件。
保留六场路线、敌方真实属性预览、首领奖励和放弃确认；移动端原生宽度布局并支持纵向滚动。

## 验证范围

- 逐项核对 21 种秘法石的名称与原始材料 ID，保护符文名称与配方。
- 探索状态机、结算、掉落、票据重试、存档兼容测试。
- 页面键盘交互、难度持久化、边界锁定、旧路由、桌面/平板/手机展示。
- 背包分页和特质解锁页的材料名称回归。
