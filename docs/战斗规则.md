      - 25%<HP≤50%: 至多轻度短效状态，通常持续1回合（移动受限、下次检定-2）
      - 0%<HP≤25%: 可产生明显伤势或重度短效状态，不能直接死亡；永久伤残优先限于非首领级敌人
      - HP≤0: 才可按玩家声明的部位描述致命、处决、昏迷或失能
    阶级限制: 首领/领主/传奇在HP未归零时，不会因一次战术瞄准永久失能
    部位效果参考:
      - 感官/发声/持武器/移动部位: 对应命中·施法·攻击·移动受罚，重度状态最多1回合
      - 核心部位: HP未归零只描述核心暴露/护甲被撬开，归零才可斩首/核心破碎
      - 痛觉弱点: 下次检定受罚，重度可跳过行动1回合
  HP叙事:
    定义: HP是体力、精神韧性、格挡余裕、求生意志与运气的综合，不等于纯肉体血量；充足时优先描述为体力消耗、格挡吃力、闪避失衡、护甲受压、运气被耗掉
    阈值:
      - >90% 健康: 行动无碍，逼退/擦边/震麻/护甲受压
      - 50-90% 受压: 喘息、架势变乱、体力下降，无严重肉体伤
      - 25-50% 受创: 可有伤口、流血、骨裂，不自动失能
      - 10-25% 重伤: 动作受拖累，站立困难，大量失血或核心不稳
      - <10% 濒死: HP>0仍可行动、反击、逃跑或拼死一击
      - ≤0 归零: 防御崩溃，允许致命伤、处决、昏迷、核心破碎、断头
    铁律: 敌人HP归零前严禁自动结束战斗；禁止剧情杀处决大量血量的敌人

# 第四阶段: 战术动作
  逻辑与规则:
    1. 附赠动作: 自己喝药可作附赠动作；喂别人喝药是主动作；附赠动作不能替代主动作攻击，除非技能/物品明确允许
    2. 反应: 常见触发=借机攻击、招架/护盾类技能、准备动作触发、明确写"反应"的能力
    3. 移动/疾走/撤离/闪避: 移动改变1档；疾走(主动作)额外改变1档；撤离(主动作)本回合离开近战不触发借机攻击；闪避(主动作)使敌人攻击劣势
    4. 物品/机关: 复杂道具/机关为主动作
    5. 准备动作: 声明触发条件与反应内容；触发时消耗反应，未触发则动作浪费
    6. 非攻击能力: BUFF、召唤、控制、治疗、结界走施法检定或属性检定；造成伤害则转入攻击动作或按技能说明结算
    7. 可抵抗效果: 目标可抵抗时额外进行属性豁免检定并输出DiceCheck

# 第五阶段: 特殊单位
  队友:
    - 命中检定 = D20 + 属性调整值；伤害按玩家/队友基本攻击公式
    - 护卫: 玩家将遭受暴击、重击、强控制，或HP将跌破50%/25%/0%阈值时，附近反应可用的队友可用反应护卫；表现为格挡、推开、屏障或分摊；无明确技能时作护卫检定，成功使命中劣势/-2、减伤或降低后果一级；同次攻击最多1名队友护卫
    - 武器面板缺失: 伤害骰按品质 普通1d6/精良1d8/稀有2d8/卓越3d10/传说3d12/史诗4d10/神话4d12；固定伤害 = floor(武器等级/4)+强化等级+属性调整值
    - 技能倍率缺失: **查<自学技能规则>**，按稀有度匹配默认倍率
  召唤物:
    - 召唤成功时输出SummonOverview
    - 攻击不消耗玩家动作，不计入玩家攻击次数
    - 多个召唤物合并为集群，合并结算只进行1次命中检定
    - **占行动轴独立回合，轮到时必须实际执行其行动，不得跳过**
  集群:
    - ≥3个同类低级单位聚合为集群，作为1个单位占行动轴1个回合，轮到时必须执行其攻击
    - 减员根据总HP百分比叙事折算

# 第六阶段: 战斗结束
  结束条件:
    - 战斗目标已完成
    - 非切磋/竞技场景不因敌人低血量自动结束；须有投降、逃跑或HP归零等明确结果
    - **只要行动轴上仍有存活且HP未归零的敌方单位，就不算战斗结束，必须继续逐单位执行回合**
  结算: 战斗结束后统一结算ExperienceLog、LootLog、熟练度、清理到期的状态完成收束
