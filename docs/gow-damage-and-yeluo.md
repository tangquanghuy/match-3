# 散射／溅射修正与叶落接入

## 当前结算

| 类型 | 公式与范围 |
|---|---|
| 普通全体伤害 | 每名敌人各受完整数值 |
| 散射 | 只计算一次总池，随机分配给存活目标；不再按每敌一份计算 |
| 普通溅射 | 主目标 100%，存活队列相邻目标各 50%，向下取整 |
| 轻度／重度溅射 | 主目标仍 100%，邻位分别 25%／75%，向下取整 |

溅射不环绕、不越过邻位扩散、不把击杀溢出转给其他敌人。多主目标各执行一波，中心死亡不取消邻位伤害。散射保留总额、使用同一种子随机源，各份额独立经过屏障／抗性／护甲／生命管线。全局加成与条件倍率先计入总池，避免每敌重复加成。状态只作用于对应波次实际命中对象，不沿用上一波的旧命中列表。

罗文尼示例：魔法 6、护甲 17 时，`6 + 3 + 17×2 = 43` 是散射总池，不是每名敌人 43 点。

## 叶落

- 部队 ID `10007`，技能 ID `20007`，史诗，红／绿，异界来客，时空裂隙。
- **猩红谢幕｜16 法力**：对一名选定敌人造成 `[魔法+4]` 点普通溅射伤害；棋盘红绿普通宝石合计每 2 颗增伤 1 点。若本次直接技能伤害击杀任意敌人（含邻位），创造 10 颗随机混合红绿宝石，每次施放一次。多杀不叠加，后续流血或宝石连锁不会重新执行奖励段；没有额外回合段。
- **血色生机**：4 连及以上，自身获得 2 生命。
- **夜铸轻甲**：骷髅伤害降低 25%。
- **赤月留痕**：配对红色宝石，随机一名敌人获得 1 层流血，沿用现有 3 回合状态／免疫机制。
- 升级数值按现有社区部队表接入：基础攻击4／护甲4／生命6／魔法1，满级表攻击17／护甲18／生命26／魔法11。
- 社区数据 → 全图鉴／王国池 → 获取与成长 → 特质解锁 → 战斗快照 → 技能注册 → 特质触发／状态结算，共用已有管线。
- 不额外向现有存档赠送角色、不替换玩家队伍。可在图鉴搜索“叶落”。
