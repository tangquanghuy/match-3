# 永生区域 PvP：用现有入侵系统承载不朽玩法


> 逐屏玩法与视觉证据已补齐，见 `docs/gow-regional-pvp-gameplay-ui-research-2026-10-01.md`。该文补充巨石碑备战、城塞投票及9.4训练/结算界面；下文首期范围仍为提案。官方血怒明确为敌方属性点+50%，此前仅加耐久的设想不是原版。

日期：2026-10-01。状态：研究与设计修订，未实施、未提交部署。

**NPC 强度修订：**见 `immortal-region-pvp-npc-design-2026-10-01.md`。成熟账号属性只作标定起点，高级区初测采用生命 3/4/5 倍、护甲 2/3/4 倍及独立输出倍率；不是同属性对战，也不是已测定数值。NPC 与真人高级区域防守的公开强化规则保持一致。


**本方案替代此前“六场递进PvE试炼”的主循环。**用户明确指出固定关卡本质仍是推图；只替换奖励和数值并不足以形成新玩法。

## 1. 官方区域PvP到底是什么

以下原版事实来自当日重新读取的官方帮助；同时核对2026-09-09的9.4更新，以及2026-08-31的Season of Mists公告。帮助页仍有“未来引入赛季”的旧段落，赛季是否存在以更新公告为准，不将帮助页每一段都视为最新。

### 异步玩家对抗，而非实时匹配

《PvP Overview》描述：玩家面对其他玩家使用过的队伍，由AI操作；进入区域后从通常分成易/中/难的3名对手中选一个，可以刷新。展示玩家等级、队伍评分以及金币/荣耀/奖杯/VP奖励。

因此当前项目的“玩家镜像+AI出手”不是替代方案，正符合原版区域PvP的基础形式。

### 十个区域与周更配队规则

|范围|区域|原版规则|
|---|---|---|
|中央环|Central Spire（中央尖塔）|无配队限制|
|内环|Aidania / Southwild / Geheron|颜色限制，白银联赛起进入|
|外环|Winter’s Reach / Ancient Khet / Bay of Stars / Maraji Expanse / Summer Isle / Broken Lands|种族或王国限制，黄金联赛起进入|

区域包含若干王国；区域名与王国名并非同一身份。限制按周变化，适用于部队/武器的具体规则由配置说明。

不朽所属区域提供两种价值：

1. 对应原技能的主场附加效果，例如特定伤害、偷取或属性增益翻倍。
2. 该不朽自身在主场忽略区域队伍限制；不是整队一起豁免。其他单位与武器仍按规则审查，每队最多一名不朽。

### 热点奖励、血怒、城塞战

- 区域银印记奖励：在带奖励的区域获胜5场后领取，奖励热点转移到别处。不同环和联赛影响数量与次数。
- 血怒：每日两个非中央区域给予敌方属性点50%加成（官方7.4更新及血怒说明配图）；胜利VP为2倍；适用区域的银印记奖励也为2倍。Victory Talisman与血怒组合为3倍VP，不是简单相乘到4倍。不是所有资源全翻倍。
- 城塞：每区域每周有一天开放争夺。不同联盟成员参与；四场对其他联盟玩家的PvP后，第五场为城塞守护者，随后继续循环，难度提高。
- 城塞按联盟总分决定归属；胜方随后有区域金印记机会，并可投票下周限制及特殊宝石（中央尖塔规则例外）。城塞守护者并不等于某名不朽。
- Monoliths为区域中的五段PvE备战玩法，提供跨区域限时PvP增益，与血怒及城塞形成备战循环。它不是全部区域PvP的主线，但应作为忠实复刻的玩法范围单独评估，避免只留下选敌与数值增长。

### 成长来源与防守差异

- 官方不朽专属灵魂来自燃烧宝箱、赛季通行证及目标；燃烧印记有赛季目标、通行证、PvP商店等来源。不是每赢一场普通区域战就必掉不朽灵魂。
- 2026-08-31赛季公告仍明确列出当季不朽灵魂来自赛季通行证/目标及燃烧箱，赛季后转为燃烧箱来源。
- 当前帮助描述：被其他人挑战的是曾出击的队伍，普通防守战只记记录，本人没有直接得失。这与本项目的独立防守、收益、复仇设计不同。
- 9.4新加“Test Defenses”供玩家测试攻防阵容、包含公会战防守选项；这条更新不等于恢复独立区域防守奖金或复仇制。
- **项目保留已实现的独立防守、积存收益和复仇，视作明确的项目扩展，不因为追求原版标签而删除。**

## 2. 项目现在有哪些可复用基础

只读核对：

- `src/meta/systems/invasionMirrors.ts`：真实阵容快照、账号身份、版本与时间、强度、近期对手去重、三档对手；现在按联赛比例尝试真人，池浅时回到NPC。
- `worker/src/mirrorPool.ts`：D1共享池按规则版本、联赛、强度、快照年龄筛选；排除自己，采样其他账号；还有周榜、实际防守记录与唯一事件写入。
- `src/meta/systems/invasionDefense.ts`：独立防守预设副本；防守入账游标、领取池、实际战报。当前成功奖励100金币/10灵魂/2荣耀，胜负影响少量VP。
- `src/meta/server/core.ts`：防守发布、战斗票、结算后防守outbox和复仇状态；复仇按已记录快照发起。
- `src/meta/systems/invasion.ts`：候选对手、血怒、金币/VP结算。
- `src/engine/skills/effects/secondary.ts`：`regionPresent`已有条件，尚无正式区域上下文贯穿请求与战斗。

**尚无：区域索引、区域有效阵容、区域战绩与榜单、区域规则版本、区域复仇上下文、真实联盟城塞归属。**这不是在UI上加几个地图标签就完成。

特别注意：目前镜像数据库的队伍记录主要按账号/联赛覆盖；缺区域维度时，上传寒冬防守可能覆盖中央尖塔防守，必须先扩契约及存储键。

## 3. 推荐主循环：入侵 → 区域选择 → 真人攻防

把区域作为现有“入侵”的战场维度，不另外造一个与它完全平行的清关活动。

> 进入本周战区 → 查看三档真人防守 → 看队伍详情并调整克制队 → 进攻拿金币/VP/区域周进度 → 配自己的区域防守 → 查看实际战报、领取收益、复仇 → 参与当期热点或挑战更强对手。

战区的意义不只是皮肤：允许阵容不同、特殊宝石不同、有效的不朽主场技能不同；防守由玩家持续调整，攻击队也要改变。这才是与固定推图的核心区别。

### 3.1 不把玩家池切成十个小池

建议首期结构：

- 中央尖塔常驻，继承当前不限制配队的普通入侵。
- 每周开放两个轮换特色战区，逐步用到十个官方区域名。中央尖塔加两个战区同时可玩；不是三个阵营，也不是三条必须刷完的日常。
- 三个场地共用同一个真人池和身份体系，用区域资格筛选；合规防守可投放到多个场地，无需防守方先在各地刷场数。
- 默认复用当前防守队；仅在某个战区不合规或玩家有针对性设计时创建区域覆盖队。最多维护当前参与的场地，不强迫配置十支队。
- 对手优先真人，不原封照搬当前按概率插真人的策略；真人不足时显式显示NPC守卫，不冒充玩家。
- 中央始终留给阵容不足的玩家；未满足当期区域资格仅影响该特色战区，不影响普通入侵。

是否最终同时开放全部十区，应依据真实有效镜像覆盖率与活跃情况再决定，当前没有以项目玩家数量为依据的十区容量测算。

### 3.2 区域规则控制在可读范围

一个特色战区同时只展示：

1. 一条配队规则；
2. 一个主要特殊宝石规则；
3. 当前不朽主场效果。

寒冬示例：本周某个具体王国或种族规则 + 冻结宝石少量出现 + 格拉西亚/双子座等在主场生效。具体种族/王国必须按区域归属和有效镜像覆盖生成，不能为了例子任意写一个不相关种族当作官方设定。

攻守双方遵循同一阵容资格和地区语义；玩家自带区域不朽只是该单位豁免，不是免掉其他三人的资格。

不额外加永久强制冻结、隐藏减伤、机关护盾去覆盖真实玩家防守逻辑。首期以既有特殊宝石/技能原语提供战场差异；新增效果必须可预览。

### 3.3 防守与复仇是真实玩家互动，不做假的领地

- 战报增加场地区域、当时规则、双方快照摘要，查看详细阵容在次级页。
- 防守收益继续积存、手动领取，沿用现有浮动金币提示。
- 复仇在原战区域和规则下进行，冻结当时对手快照，不被对方之后改队替换。
- 当前复仇快照可能优先使用攻击者配置的防守队；若该队不符合原战区，应在战报生成时选择合法的区域防守队，否则使用原进攻阵容，并明确显示“复仇对阵”。不是事后随意抓取任意阵容。
- 跨周旧规则复仇保留为独立旧战报处理，计分/额外成长奖励截止与原周期一致；不灌进新周的燃烧灵魂额度。普通复仇收益另按统一策略控制。
- 保留全局VP和防守微量VP变化；区域榜首期只统计有效主动进攻得分，不再对同一防守失败额外扣一次区域分。
- 榜单展示真实玩家战绩；榜首是区域周冠军，不叫“占领者”。真正城塞占领需要共享归属、贡献结算及防守状态，首期尚无这些系统。

### 3.4 热点引导与对抗目标

- 每周两个特色战区中提供清晰的热点加成；不用轮流完成固定六场才解锁地图。
- 奖励周总额固定，不设每日必须清空的小上限；错过某天不会永久少拿燃烧灵魂。
- 可借鉴官方血怒，提供明确标记的高风险对手或热点时段。但敌方增强、VP加成、额外资源需分别预览，不把所有奖励乘倍。
- 榜单用于竞争荣誉、称号，不垄断核心燃烧灵魂，减少人口规模和在线时长带来的差距。
- 防守提供实际改变对手选择与战斗结果的空间：看到战报后改防守、围绕区域主场效果设计反制，而非只比累计打了多少场。

## 4. 高难活动与燃烧灵魂怎么放

原来的“永生神试炼”不再是六个固定节点，改为区域PvP中的周征战奖励与高难目标。

仍保留“普通周活同级宝石/金币/印记 + 燃烧灵魂”的方向；此前600宝石、80燃烧灵魂只是预算草案，不因为取消六关就随每场胜利无限增发。

建议分成两个来源，而非把稀有奖励全部绑定榜单：

- **稳定部分**：当周特色区域有效战斗贡献达到里程碑，发普通周活资源和大部分燃烧灵魂。合法NPC守卫胜场也提供基础参与路径，但不伪造真人战绩。
- **高难部分**：击败达到绝对养成门槛和合理相对强度的对手，取得本周限量燃烧灵魂加成；不能通过主动脱装备、换弱队把普通对手伪装成高难。
- 真实高难镜像不足时，提供公开标记的高难永生神守护者作为补充途径；直接挑战，不要求先刷四场、不锁PvP入口。它与高难真人胜场共享同一额外供给上限，不重复开第二份预算。
- 同账号对手的重复交战按周期限制额外收益；复仇不重置该额度。防守和双方投降不产生燃烧灵魂。
- 区域积分是展示/进度，不是又一种可消费货币。复用现有活动印记商店结构，不同时引入金印记、银印记、燃烧印记三套兑换。
- 燃烧灵魂保持通用、永久，升级仍为普通灵魂+燃烧灵魂；已有等级不追缴。

数值应在确定真人/NPC占比、单场时长、高难候选覆盖与反互刷规则后重算，不把“198升级成本/80周产出”当作已定案经济。

## 5. 为什么首期不直接照搬联盟城塞战

官方城塞有联盟、全服归属、指定开放日、符印投入、争夺后投票。项目目前确认的是个人镜像与榜单，不是完整联盟争夺。

个人区域PvP可以先做成完整闭环：对手变化、规则周更、防守收益、复仇、周冠军、成长奖励。

真正的城塞争夺留后续：

- 明确联盟/公会归属和人数差距处理；
- 共享贡献、占领状态和奖励一次性结算；
- 多账号刷贡献、弱阵容互喂、开服低人口时无人争夺等防护；
- 投票结果与下周阵容规则版本衔接。

没有这些前置时，给一个人机首领挂“城塞”名字，不会自动产生PvP领地争夺体验。

## 6. 技术接入重点

1. 正式`regionId`/`regionRuleRevision`贯穿区域计划、镜像资格、战斗票、初始状态、回放、续战、奖励与战报。保持`kingdom`与`region`独立；区域入侵才启用PvP模式。
2. 镜像按所有者+防守槽/区域配置版本存储；默认队可映射多个合法区域。查询去重按所有者，不能同一玩家三个防守塞满三档。
3. 现有`teamPower`只是四维加权，区域双倍技能与特质不会自然反映进去。匹配需结合账号养成、实际阵容和区域能力；展示评分不把施法倍率当成永久魔法属性写入快照。
4. 区域有效性不能在SQL先取200条后简单过滤完就当无真人，考虑可索引的资格/标签或有上限的补采样；默认不扫描全库，也不加三倍顺序远程请求。
5. 默认防守与区域覆盖的发布去重键纳入区域/规则版本，避免`shouldPublish`因阵容未变而漏发新周规则信息。
6. 开战时固化敌方快照、区域、血怒状态、难度/奖励依据；更新防守不影响进行中的战斗，结算不拿最新快照反向否决旧票。
7. 防守outbox及D1唯一写入继续沿用，加入区域元信息；服务端提供身份/胜负事实，客户端不直接决定区域分或资源。
8. 新增周进度与结算账本，幂等处理攻击奖励、镜像战报、防守入账、复仇消耗、额外成长额度，避免跨账号部分失败造成重复奖励。
9. 随机转化、复制召唤补查单队一不朽边界；这是此前开战限制之外的独立风险，不在本文声称已修。
10. 页面预取本区三档候选与详情资源，沿用等待网络提示；不让整个战斗棋盘因拉取其他区域/榜单进入阻塞态。

## 7. 界面组织

- 入侵首页：区域地图/当期热点、当前全局段位、周奖励进度；原普通入侵默认落中央尖塔。
- 进入区域：领域背景、极简规则、城塞/巨石碑地标与挑战入口；三档选敌独立次级页，战前与部队详情再分层。
- “我的防守”“战报/复仇”“区域榜”是独立次级页，PC也如此；避免塞在同一屏底部裁切。
- 对手详情清楚显示真人镜像或NPC、阵容、区域生效技能、奖励；不展示需要频繁手算的新指标。
- 防守收益仍有金币提示；不重复增加累计被入侵总次数等无决策价值的大统计条。
