# 入侵：VP 官阶、手动领奖与无限刷新

本文件取代旧设计中「周榜名次决定普通官阶升降」和「每天只更新一次候选」的条款。与活动模式的“入侵/守土”奖励是两套系统，本次不调整活动奖励。

## 官方核对与边界

核对日期：2026-09-27（UTC）。官方来源：

- PvP Overview：`https://infinityplus2.freshdesk.com/support/solutions/articles/150000208328-pvp-overview`
- PvP Leaderboards & Scoring：`https://infinityplus2.freshdesk.com/support/solutions/articles/150000208175-pvp-leaderboards-scoring`
- 7.3 Battlegrounds：`https://gemsofwar.com/7-3-update-battlegrounds/`
- 7.5 United We Stand：`https://gemsofwar.com/7-5-update-united-we-stand/`

必须区分三个官方系统：

1. **联赛**有十种名称，采用每周小组排名升降，不是纯 VP 门槛。最高钻石也存在降级区；此前项目常量把钻石写成不降级，不能据此反推官方规则。
2. **PvP Goals**有 20 个周目标，VP 达标后进入目标页面手动领取。官方奖励包括银/金印记和限时加成，不是本项目的宝石表。官方帮助页截图能直接读出的目标 1–7 为 **50、100、200、300、450、600、800 VP**。截图已存入 `data/reference/gow-pvp/official-pvp-goals.png`。本次没有从该截图推断其余 13 个官方门槛。
3. **联盟官阶**在 7.5 官方说明中为 18 阶，需要赛季 VP 和忠诚度，不等于青铜至钻石联赛。

官方 Overview 支持三名候选和刷新，并说明刷新可能再次遇到同一对手。**本项目的免费、无限次、持久化刷新，以及“普通阶纯 VP、最高阶开放周榜”的组合，是按产品要求作出的适配。**不宣称它就是官方完整官阶系统。

## 本项目每周 30 阶（2026-09-28 调整）

本节取代此前的永久累计 VP / 一次性 465 宝石方案。现在每周共 **6000 宝石**，最高阶 **8000 VP**。周一零点按项目本地日历重置；本周未领取奖励过期。

|---|---:|---:|---:|
| 青铜 | 0 / 50 / 100 | 50 | 150 |
| 白银 | 200 / 300 / 450 | 75 | 225 |
| 黄金 | 600 / 800 / 1000 | 100 | 300 |
| 白金 | 1250 / 1500 / 1750 | 125 | 375 |
| 翡翠 | 2000 / 2300 / 2600 | 175 | 525 |

第一阶是进入玩法后可领的 50 宝石。每阶每周领取一次，重读存档、重复点击或刷新对手均不重复发奖。旧方案已领取的记录在当前周保留，不补发差额；下周开始使用完整新奖励表。

### VP 与场数

| 普通对手档位 | 每胜 VP | 从 0 到满进度的胜场（无血怒） |
|---|---:|---:|
| 低档 | 10 | 800 |
| 中档 | 20 | 400 |
| 高档 | 30 | 267（8010 VP） |

- 这是**胜场**要求，不是包含战败的总场数。
- 普通对手固定 1:2:3，不随官阶、敌人平均等级、回合数、存活人数、额外回合变化。随机血怒对手额外乘以 1.5 或 2；页面直接显示倍率后的确切 VP。血怒胜利可减少打满周进度所需的胜场，周奖励总额仍为 6000 宝石。
- `progressionVp` 是本周胜利累计 VP，失败不扣，用于晋阶和领奖。
- `vp` 是周榜 VP，胜利加同样的分数，战败扣 5，保底 0。
- 每周重置以上两个积分、当前官阶、本周战斗次数和 `claimedRanks`；历史最高官阶、钱包和免费刷新计数保留。当前官阶不会从历史最高官阶恢复。
- 达标立即晋阶，无需先领奖。只有钻石 III 展示周榜；普通官阶不看排名。没有额外的旧版周结宝石。
- 本表和周场数目标为项目设计，不是官方原版数值。开头官方资料仅用于区分系统与确认早期门槛参考。

## 随机血怒（项目自定数值）

- 每批三名候选有 **25% 概率**出现一名血怒对手，其余 **75%** 批次没有血怒；每批至多一名，至少保留两名普通对手。不是每次刷新必出，也没有保底计数。
- 血怒中 **75%** 为 VP ×1.5、四维基础属性 ×1.25；**25%** 为 VP ×2、四维基础属性 ×1.5。四维按生命、护甲、攻击、魔法计算，向上取整且遵守战斗快照属性上限，零值保持为零。
- 低、中、高档血怒胜利分别获得 **15 / 30 / 45 VP**（×1.5）或 **20 / 40 / 60 VP**（×2）。败场仍只扣周榜 5 VP，不扣晋阶 VP。
- 血怒提高随机配队筛选标准，扩大协同候选采样、降低随机扰动、要求供魔支持并选择匹配旗帜。稀有度加权随机池继续生效，不改成少数固定命名组合。
- 血怒保持所属官阶与档位的部队等级及特质解锁门槛；提升属性不等于低级解锁全部特质。普通对手、竞技场和其他关卡不获得血怒属性加成。
- 随机结果由周次、官阶组、刷新代数确定：同一候选批次重绘或读档不重抽，手动免费刷新才进入下一批（周次或官阶组变化也会重建候选）。
- 属性分按强化后的实战四维计算；奖励预览和结算共用倍率函数。开战快照保留配队、属性加成和 VP 倍率，跨周结算继续使用开战对手。
- 主卡采用暗红底色、红色队伍边框、缓慢呼吸光晕与细边流光；倍率徽记只显示「血怒 VP ×1.5 / ×2」。特效不遮挡立绘与文字，系统启用减少动态效果时关闭动画。

## 刷新、领奖与跨周战斗

- 对手免费无限刷新，无冷却。刷新会重建随机阵容，三档各一队；稀有度随机池和少量社区参考阵容规则保持。
- 榜单种子独立于刷新种子；刷新不影响积分和领奖状态。
- 对手 ID 携带周次、官阶组和刷新代数，旧卡片不会指向新阵容。
- 领奖前网关核对当前周次；旧周页面的请求触发周刷新但不领取新周奖励。拒绝倒退周次，避免旧请求重置领奖记录。
- 网关保存开战对手快照及 requestId。跨周战斗按原阵容与难度结算，VP 计入**结算所在周**；即便中途已同步新周，也不覆盖新周进度和领奖记录。成功后清除请求，重复结算不发奖。
- 刷新使进行中的旧战斗请求失效。

## 存档兼容与经济预算

- 旧档本周已经保存的 VP 与领取记录继续保留；首次跨周统一重置。
- 极老档缺少 `progressionVp` 时，兼容迁移仍保留一次历史官阶门槛下限；下一周归零后，新字段为准，历史最高阶不再回填。
- `gemBudget` 新增显式 `invasionWeeklyVp` 输入，按达到的官阶汇总每周可领宝石，上限 6000；未填写不虚构每周满勤收入。
- 旧 `invasionDistribution` 仅保留输入兼容，不再产生旧制排名结算收入。

## 页面与图标

- `#invasion/ranks` 独立分页：桌面每页六阶，手机每页三阶；显示本周进度、门槛、待领总额、每周 6000 宝石和重置说明。
- 主对手页没有配队攻略、固定组合名称或策略标签。
- 继续使用十组不同纹章 × 三种分阶标记的 30 枚独立 SVG 图标。此前文生图工具未返回可用素材。

## 验证

覆盖无血怒三档实际从零打满所需的 800 / 400 / 267 胜、每周 6000 奖励总额、重复领取、跨周清零与再次领取、旧周请求、刷新免费、对手阵容保持、跨周战斗、重复结算及桌面/手机页面。

血怒专项覆盖一万批随机分布与稳定性、三档和多个官阶的两种倍率、真实战斗属性/特质/旗帜、预览与结算一致性、存档重载及 1600 / 390 / 320px 页面、减少动态效果。
