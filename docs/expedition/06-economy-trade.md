# 深渊远征 · 通货与交易行（第三版新增）

日期：2026-10-28。状态：提案，未实施。

本项目没有付费商城（`economy.ts` 注释写明“单机版没有商城”），宝石只能在游戏里获得。交易行是玩家之间第一次互相交换物品，会把“刷出来的东西”变成所有人共享的经济，所以本文对安全前提写得比较严。

## 1. 参考的商业做法

| 游戏 | 借用的做法 | 用来解决什么 |
| --- | --- | --- |
| 火炬之光：无限 | 统一的交易货币（初火源质）；交易行支持一口价和查价；市场价格决定“刷什么” | 让不同刷法的产出可以互换 |
| 流放之路 | 交易货币本身就是做装通货，有真实用途，所以有持续消耗 | 货币不会只进不出 |
| 塔科夫 | 跳蚤市场有等级门槛和手续费；“局内带出”（Found in Raid）标记：只有自己带出来的物品才能卖，买来的不能转卖 | 搜打撤和交易的天然结合；防止倒卖洗钱 |
| 暗黑 4 | 绑定和可交易的物品分开 | 关键进度不能用钱买 |

## 2. 通货分层

| 层 | 内容 | 能否交易 | 原因 |
| --- | --- | --- | --- |
| 主线资源 | 金币、灵魂、宝石、荣耀、金钥匙、现有材料（钢锭、符卷、特质石、藏宝图） | 不能 | 一旦能交易，远征以外的养成就可以“买”出来，外面的平衡会被打穿 |
| 交易货币 | 重铸石（小额）、破限石（大额） | 能 | 两者都有真实的做装用途（重铸、定向重铸、路引重铸；加护、破限、路引腐化），交易之外也在持续消耗（`11` §7） |
| 做装通货 | 升品石、升阶石 | 能（订单簿） | 低价值，流动性好；参考价 0.5 / 0.3 重铸石 |
| 刻尘 | 刻尘 | 不能 | 分解自己的刻印得到，用于铭刻。不能交易，重建主要靠自己分解（`11` §7.3） |
| 远征物品 | 刻印、路引、罗盘 | 能（受“带出标记”约束，§3） | 交易行的主体 |
| 事件货币 | 裂片、梦尘 | 能 | 让不刷裂隙、梦境的玩家也能用上裂隙孵化台和梦境灌注 |
| 事件货币 | 猎人徽记、金库币 | 不能 | 猎人等级和金库商货架要靠自己参与事件解锁 |
| 记忆碎片 | 按“记忆 + 编号”区分（`07`） | 能（受带出标记约束） | 熔炉材料通过碎片间接流通 |
| 熔炉材料 | 宝珠、塔罗牌、诅咒符文、龙晶、宝石珠/碎片/钻石、召唤水晶 | 不能 | 只能由自己拼成的记忆开出，直接进主线库存。交易行不开放主线材料（用户裁定） |
| 王国纹章 | 各区域纹章 | 能（受带出标记约束） | 王国 11–15 级可以用交易补短板 |
| 宠物 | 宠物粮；除老鼠、猎犬外 10 种宠物的蛋 | 能（蛋受带出标记约束，买来的蛋绑定） | 老鼠、猎犬在远征外加金币、灵魂，它们的蛋绑定；3 换 1 换出的蛋、孵化后的宠物绑定（`08` §11） |
| 绑定物 | 燃烧灵魂、刻尘、铭文库、星图、寻回罗盘、拼好的记忆、孵化后的宠物、老鼠和猎犬的蛋、3 换 1 换出的蛋、升阶保底加成、新手和委托赠送的物品、首领变体解锁 | 不能 | 账号进度和兜底机制 |

为什么不用金币或宝石当交易货币：

- 金币是王国升级的主要消耗。用它交易，主线经济会被远征市场拉动。
- 宝石能直接换部队。用它交易，等于部队可以在玩家之间买卖。

## 3. 带出标记（来自塔科夫的“局内带出”）

- 撤离时入账的远征物品和局外材料，都带“带出”标记，可以上架。
- 在交易行买到的物品：
  - 刻印、带词缀的路引：成交后绑定买家，不能再上架；
  - 可堆叠的物品：进入该物品的“绑定数量”。每种可堆叠物品存两个计数——可交易数量和绑定数量。
- 做装不改变标记：自己带出的刻印，升阶、重铸、铭刻之后仍然可以卖。这让“做装师”成为一种成立的玩法：收底子、做好、卖成品。但买来的刻印即使做过装，也还是绑定的。
- 交易货币（重铸石、破限石）和做装通货（升品石、升阶石）本身就是货币，不分标记，全部可以流通。刻尘不能交易。
- 效果：
  - 物品只能从“带出它的人”流向“使用它的人”一次，倒卖和小号转移价值都很难；
  - 搜打撤的意义被放大了：带出来的东西不只能用，还能卖。

## 4. 交易行规则

### 4.1 两种挂单

| 类型 | 适用 | 机制 |
| --- | --- | --- |
| 订单簿 | 可堆叠物品：通货、材料、罗盘（按种类和阶）、事件货币、无词缀路引（按阶） | 买单和卖单自动撮合，可以部分成交；按价格优先、时间优先 |
| 一口价 | 唯一物品：刻印、带词缀的路引 | 卖家定价，买家直接购买 |

刻印求购单（三期）：买家写好筛选条件（品质、底材、词缀和最低 T 级）并冻结货币，有符合条件的刻印上架时，卖家可以直接卖给他。

### 4.2 计价

- 订单簿和一口价都可以用重铸石或破限石计价。
- 重铸石 ↔ 破限石本身有一个订单簿，汇率由市场决定。
- 价格信息：
  - 每种可堆叠物品显示 7 日成交中位价、成交量、最近 10 笔成交；
  - 刻印显示“相似刻印”的近期成交价，相似的定义是同品质、同底材、主要词缀相同。

### 4.3 费用（同时是通货回收）

| 费用 | 规则 |
| --- | --- |
| 上架费 | 标价的 1%，最少 1 重铸石；不退 |
| 成交税 | 成交额的 8%，由卖方承担 |
| 撤单 | 不退上架费 |
| 有效期 | 48 小时，过期后物品退回交易行收件箱 |

### 4.4 限制

| 项目 | 规则 |
| --- | --- |
| 资格 | 远征等级 ≥ 10，账号创建 ≥ 7 天，已完成新手引导 |
| 挂单数量 | 按远征等级 5 → 30 |
| 每日成交额度 | 按远征等级，以重铸石折算计 |
| 价格区间 | 可堆叠物品挂单价必须在 7 日中位价的 0.25–4 倍之间（没有成交历史的物品不限）；刻印设置按品质的最低价 |
| 交易渠道 | 没有面对面交易、赠送或邮寄，所有交换都经过交易行 |

### 4.5 交割

- 买到的物品和卖出的货款，都进“交易行收件箱”，玩家手动领取到仓库。
- 仓库满时，物品在收件箱保留 7 天，到期作废并发邮件告知名称和数量。
- 离线时成交，上线后收件箱有红点。

### 4.6 回收商（价格地板）

营地有一个 NPC 回收商，按固定低价回收任何可交易物品，只付刻尘，例如刻印按分解价的 1.5 倍给刻尘。回收商不产出任何交易货币或做装石（`11` §7.3），所以它只给市场一个“不如卖给回收商”的下限，不会变成印钞口。垃圾物品也不会挂满交易行。

## 5. 服务端结构

现状：每名玩家一个 Durable Object（`worker/src/playerActor.ts`）保存存档；跨玩家的数据在 D1（镜像池、周榜、防守记录）；跨账号的投递已经有 outbox 模式（入侵防守的 `defenseOutbox`）。

交易行在这个基础上新增：

- MarketActor：按品类分片的 Durable Object，例如刻印一片、通货与材料一片、路引与罗盘一片。
  - 每一片单线程处理撮合，天然没有并发竞争。
  - 它持有订单簿和托管（escrow）的物品。
- D1 表：
  - 挂单索引，供搜索使用（刻印按品质、底材、词缀、T 级建索引）；
  - 成交记录、价格历史；
  - 只追加的交易账本（交易 ID、物品快照、价格、双方账号、时间）。

流程：

1. **上架**
   1. 玩家命令到达 playerActor：把物品从存档移入“托管中”，同时写一条 outbox 记录（挂单 ID）。
   2. MarketActor 按挂单 ID 幂等地创建挂单。
   3. 被拒绝时（违反价格区间、超出数量），通过 outbox 原样退回。
2. **购买**
   1. playerActor 先冻结买家的货币。
   2. MarketActor 撮合成交。
   3. 向买家投递物品、向卖家投递货款（扣除税费）。每笔投递带交易 ID，玩家 actor 幂等地应用。
3. **对账**：定时任务比对账本、托管和投递状态，修复“已扣款但没投递”这类中间态。

接口全部需要现有的 Discord 登录会话，并沿用现有的限流。客户端只能提交意图，价格、撮合、扣款都在服务端完成。

## 6. 反作弊与反现实交易（上线交易行的前提）

现状：战斗胜负由客户端上报，服务端只校验 requestId 和规则版本。不开交易时，作弊只影响作弊者自己；开交易之后，作弊产出会流向所有玩家。所以以下几项是交易行上线的前提，不是“以后再做”：

1. **战斗结果服务端校验**：引擎是确定性的（同一个 seed 和行动序列会得到同一个结果）。
   - 对“会产出可交易高价值物品”的战斗（领主、首领、悬赏目标、事件首领），服务端用行动日志重放校验，全量执行。
   - 其他战斗按比例抽检。
   - 这需要客户端上报完整的行动序列。现在已有的 `actionLogDigest` 只是摘要，要扩成可以重放的日志。
2. **异常检测**：按账号统计每阶的胜率、回合数、掉落数量，和同装备增益的分布比较，超出阈值的账号冻结交易权限，等待人工复核。
3. **交易图谱检测**：
   - 同一卖家对同一买家反复以远低于中位价成交；
   - 新账号单向输送价值。
   
   这两类自动标记。
4. **处置**：封禁交易权限；按账本回滚涉及的成交。账本是只追加的，回滚以反向交易记录，不删除历史。
5. **说明**：场外的现实货币交易（RMT）无法完全杜绝。上面的措施只能把成本提高到不划算。

## 8. 经济平衡

交易货币的产出和消耗：

| 通货 | 产出 | 消耗 |
| --- | --- | --- |
| 重铸石 | 稀有怪、领主、魔方 SR 档、恩惠商店 | 重铸、定向重铸（×3）、路引重铸、上架费、成交税 |
| 破限石 | 首领、魔方 SSR 档、阶 7 以上的上锁宝箱 | 加护、破限（每件最多 6 枚）、路引腐化、上架费、成交税 |
| 升品石 | 稀有怪、领主 | 升品、路引加词缀 |
| 升阶石 | 普通战斗、补给 | 升阶 |
| 刻尘（不可交易） | 分解、普通战斗、补给、回收商 | 铭刻 |

各深度的期望产出见 `11` §7.1。没有任何兑换配方能产出重铸石或破限石。远征失败时，丢失刻印上花过的通货一起离开经济；目标是这部分占交易货币总回收的 25–40%（`11` §8.6）。

监控指标：

- 每周两种交易货币的总产出、总消耗、存量；
- 市场价格指数；
- 成交额集中度：前 1% 账号占比。

调节手段，按优先级：

1. 调成交税；
2. 调做装消耗；
3. 最后才调掉落。

金币不进交易行。猎金是金币的主要来源，王国 11–15 级是主要消耗（每国 20 万，42 国合计 840 万）。

## 9. 已定的产品决定

1. 熔炉材料不直接交易。它们由记忆碎片拼成记忆后随机开出，流通的是碎片（`07`）。
2. 交易行不开放主线材料。

## 10. 待设计备忘：底价扫货

只记录方向，暂不做具体设计：

- 每种可交易物品要定一条“底价”。
- 低于底价的挂单，由后台脚本直接买下，从市场上移除。
- 作用：
  - 防止有人用极低价向小号输送价值；
  - 给市场一个价格下限，和回收商（§4.6）配合。
- 实施时要定清楚：
  - 底价怎么计算（按回收价、7 日中位价的比例，还是人工表）；
  - 脚本买下的物品如何处理（销毁或回收进奖池）；
  - 卖家得到的是底价还是挂单价；
  - 这些成交是否计入价格历史（建议不计入，避免拉低中位价）。
