# 深渊远征 · 地图事件（第二版）

地图事件是远征的主要玩法内容，由罗盘插入，或者由空罗盘槽随机出现（`01` §2.2）。

每个事件都必须同时具备下面七项，缺一项就不上线：

1. 局内玩法：玩家在地图层和三消战斗层分别做什么。
2. 押注点：什么时候继续、什么时候收手。
3. 专属货币：事件内获得，撤离时结转。
4. 兑换或制作系统：专属货币怎么变成价值。
5. 首领链：日常产出 → 钥匙 → 事件首领。
6. 放大旋钮：罗盘的阶、遗珍变体、叠加规则，以及星图星群。
7. 实现要点：用到哪些引擎原语、服务端状态、需要新增什么。

数值都是设计值，按 `01` §3.4 的期望收益目标校准。

## 总览

| 事件 | 原型 | 一句话 | 主要产出 | 期 |
| --- | --- | --- | --- | --- |
| 血祭 | 流放 2 仪式 | 在祭坛范围里打过的敌人会一起复活成车轮战，用贡品买恩惠、延期或献给王 | 刻印、记忆碎片、指定物品 | 一 |
| 魔方 | 火炬魔方 | 用欲念结晶抽卡，越抽越容易激怒，激怒就全丢 | 做装通货、刻印 | 一 |
| 裂隙 | 流放 2 裂隙 + 火炬叠界 | 限步数的裂隙区，按回合评级拿裂片，用裂片定向孵化刻印 | 定向刻印、路引 | 二 |
| 猎金 | 宝石战争赏金 + 火炬狩猎 + 流放 2 监督者石板 | 接悬赏追猎首领级目标，自己给目标加码，连猎叠倍率；队里的“赏金猎人”特质部队直接翻倍赏金 | 金币、猎人徽记、目标专属掉落 | 二 |
| 梦境 | 火炬梦魇 + 流放 2 谵妄 | 逐层下潜，奖励泡影逐层升级，噩梦概率逐层上升 | 梦尘（给刻印灌注特质） | 三 |
| 金库 | 流放 1 Heist + 火炬通缉 | 警戒值驱动的劫案，队伍里的部队种族提供地图技能 | 记忆碎片（可以定向买缺的编号） | 三 |

产出互相喂养：

- 魔方产重铸石和升品石，用来做路引和刻印；
- 猎金的悬赏令让玩家“点名刷”某个首领的专属掉落，同时是金币的主要来源；
- 梦境的灌注依赖稀有以上的刻印；
- 金库产记忆碎片，并且可以定向买缺的编号，用来拼出熔炉材料（`07`）。

大部分产出可以在交易行流通（`06-economy-trade.md`），所以专刷一个事件、换取其他产出也是成立的玩法。

玩家会按自己的需求和星图专精，在 6 个事件之间切换刷法。

## 1. 血祭

### 1.1 局内玩法

**地图层**

- 每个罗盘阶给 1 座祭坛（节点）。祭坛的献祭范围是祭坛节点本身加上相邻节点。
- 祭坛激活之前，在献祭范围内打过的战斗都会被记入“祭坛名单”：
  - 记录内容是敌方每个单位的部队、等级、怪物稀有度和词缀；
  - 名单上限 8 个单位；
  - 稀有怪物和稀有怪巢的敌人也会被记入。
- 玩家可以主动绕路进入范围作战，也可以等游荡敌人经过范围时再打，以此挑选名单内容。

**激活祭坛（2 步）：祭仪战**

- 这是一场三消战斗。名单上的前 4 个单位先上场。
- 每个上场单位都带一条“血祭召回”（`summonOnDeath`，概率 1），阵亡后由名单上的下一个单位补进空位。名单打完，战斗才算胜利。
- 复活的单位额外 +1 条词缀“血祭”：开局 15% 法力。
- 队伍生命跨战延续，车轮战的消耗是真实代价。
- 这场战斗算 2 场战斗的步数（4 步）。

**贡品**

- 每个单位的贡品值按怪物稀有度计：普通 10、魔法 20、稀有 45、首领级 80，再乘以路引阶的系数。
- 战败或撤退，本座祭坛的贡品为 0。

### 1.2 押注点

- 绕进献祭范围多打一场：多一个名单单位，多一份贡品，但也多一份车轮战消耗。
- 恩惠商店：现在买、重抽、延期、还是献给王（§1.4）。

### 1.3 专属货币：贡品

- 只在本座祭坛的恩惠商店使用，或者献给王。
- 离开祭坛时没花完的贡品，可以全部献给王，否则作废。

### 1.4 兑换：恩惠商店

祭仪战胜利后，商店随机陈列 8 件恩惠：

- 刻印（按品质）、路引、罗盘、重铸石、升品石、升阶石、记忆碎片、宠物粮；
- 以及之前延期过的物品。

| 操作 | 效果 |
| --- | --- |
| 购买 | 花贡品，物品放入背包，尚未带出 |
| 重抽 | 每座祭坛免费 1 次，之后每次花当前总价的 10% |
| 延期 | 付该物品价格的 15%，把它记入“延期名录”。它会在以后的祭坛里以 90% 的价格重新出现；名录容量 5，可以通过事件营地扩容。延期过的物品不能再延期 |
| 献给王 | 剩余贡品立即计入“王之召见”进度，永久保存，不会因为失败丢失 |

这就是流放 2 仪式里“三者抢同一份预算”的结构。本作额外有一层：

- 买东西：放进背包，失败就会丢；
- 献给王：永久进度，不会丢。

所以“贪当下的物品”和“攒稳的进度”是真实的取舍。

### 1.5 首领链

1. 王之召见进度达到 3000：下一趟远征必定出现“雾中之王”首领殿。
2. 击败雾中之王，掉落“王首”。
3. 王首可以合成“无名之仪”路引：
   - 一张图里有 3 座祭坛；
   - 前一座祭坛的名单会全部继承到下一座；
   - 最后一座同时召回 4 名首领级单位。
4. 击败最终的“无名者”，掉落必定史诗的刻印和稀有铭文。

### 1.6 放大旋钮

**罗盘**

| 罗盘 | 效果 |
| --- | --- |
| 一阶 | 1 座祭坛 |
| 二阶 | 名单上限 8 → 12 |
| 三阶 | 再加 1 座祭坛 |
| 遗珍·血债 | 名单单位全部额外 +1 条词缀，贡品 +60% |
| 遗珍·宽恕 | 延期费用 15% → 5% |
| 遗珍·献王 | 献给王的贡品 ×1.5，但恩惠商店只剩 4 格 |

**星图 · 血祭星群**

| 写法 | 节点 |
| --- | --- |
| 出现率 | 空槽随机出现血祭的概率 +10% |
| 改变形态 | 祭仪战改为名单全部单位一次上场，分两批（4 + 4），贡品 +40% |
| 规则 | 已经献给王的贡品，也可以拿来支付延期 |
| 规则 | 重抽次数 +1 |
| 代价交换 | 恩惠商店不再出现刻印，记忆碎片数量 ×2 |
| 范围 | 献祭范围 +1 步 |

### 1.7 实现要点

- 车轮战补位用的是现有 `summonOnDeath`（死亡后进入空位）。召回单位要带名单记录的属性、等级和词缀，必须使用 `DeathSummonContext.resolveTemplate` 的单场解析器，并在 BattleRequest 里携带名单快照。否则召回的单位会按兵种原始数据入场，丢失词缀和缩放。这是需要新增的接线。
- 名单、商店、延期名录、王之召见进度都由服务端保存：前两项在 run 状态里，后两项在 `eventProgress` 里。
- 上线前评估：8 个单位的车轮战时长，目标 ≤ 普通战斗的 2 倍。

## 2. 魔方

### 2.1 局内玩法

**地图层**

- 每个罗盘阶在中环刷 2 名“恶欲化身”（游荡稀有怪），魔方本身在内环。
- 击败恶欲化身获得欲念结晶，计入本趟事件账户。

**战斗层**

- 恶欲化身的战斗里会掉落“结晶宝石”（特殊宝石，每回合 5% 几率生成）。我方每匹配一颗，+2 结晶。
- 战斗里的取舍：先拿结晶宝石，还是先杀人。

**在魔方前“渴求”**

- 每次渴求消耗结晶：第一次 10，之后每次 +5。
- 每次翻开一张奖励卡，分五档：N / R / SR / SSR / UR。卡上的奖励先放进“魔方奖池”，还不在背包里。
- 每次翻卡后，“怒气”增加，增量按卡的档位：N +6、R +9、SR +14、SSR +20、UR +25。
- 下一次渴求被激怒的概率就等于当前怒气值（%），在按钮上直接显示。
- 随时可以“满足”收手：奖池里的东西全部放入背包。

**激怒**

- 奖池清空。
- 强制进行一场“极欲化身”战（首领级，带 2 条词缀）。胜利只补偿 1 张 SR 卡。

### 2.2 押注点

每一次渴求都是一次“继续还是收手”，概率完全透明。这是火炬魔方的原型。

### 2.3 专属货币：欲念结晶

- 本趟有效。撤离时没花完的结晶作废（星图可以改成按比例结转）。

### 2.4 奖励卡池

| 档 | 奖励 |
| --- | --- |
| N | 刻尘、局内素材 |
| R | 升阶石、精良刻印 |
| SR | 重铸石、升品石、稀有刻印 |
| SSR | 破限石、史诗刻印、高一阶路引 |
| UR | 欲念之核（首领链）、破限石 ×3 |

神话刻印不进魔方卡池。神话只来自淬火和终极首领、传奇悬赏的掉落（`11` §4.2）。

### 2.5 首领链

集齐 3 枚欲念之核：开启“极欲之主”首领殿，击败后掉落罗盘遗珍变体和神话刻印。

### 2.6 放大旋钮

**罗盘**

| 罗盘 | 效果 |
| --- | --- |
| 一阶 | 2 名恶欲化身 |
| 二阶 | 4 名恶欲化身 |
| 三阶 | 再加 1 座魔方，两座魔方怒气独立计算 |
| 遗珍·奇遇 | 换成 3 座迷你魔方，每座只能抽 4 次，怒气独立，奖池品质 +1 档 |
| 遗珍·双极 | 恶欲化身 +2，但渴求费用 +50% |
| 遗珍·节制 | 怒气增长 −30%，但最高只到 SSR |

**星图 · 魔方星群**

| 写法 | 节点 |
| --- | --- |
| 规则 | 第一次渴求不增加怒气 |
| 规则 | 激怒时保留奖池里最高档的 1 张卡 |
| 概率 | 每次渴求 5% 几率不消耗结晶 |
| 代价交换 | 魔方不再出刻印，所有刻印格改为重铸石或升品石 |
| 结转 | 撤离时 50% 的结晶结转到下一趟 |

### 2.7 实现要点

- 抽卡和激怒判定在服务端按 run seed + 动作序号抽定。奖池状态保存在 run 里，刷新不会重抽。
- 结晶宝石需要新增一个战斗内经济键（现有的战斗内收集只有金币、灵魂、宝石和藏宝图）。结算时把该键的实际值写入事件账户，并在战斗结算页“放入背包”区域显示为“欲念结晶 +N”。

## 3. 裂隙

### 3.1 局内玩法

**地图层**

- 罗盘在中环生成一个“裂隙之手”节点。触碰它，裂隙打开，持续 8 步。
- 裂隙打开后，在裂隙之手周围生成 3–5 个临时的裂隙节点，每个节点一场裂隙战。
- 裂隙关闭时，没打的裂隙节点消失。

**战斗层：回合评级**

- 每场裂隙战有一个目标回合数 T，按敌方总生命和我方输出估算。
- 评级：

| 评级 | 条件 | 裂片 | 裂隙时长 |
| --- | --- | --- | --- |
| S | 回合数 ≤ T | 30 | +2 步 |
| A | 回合数 ≤ 1.5T | 18 | +1 步 |
| B | 其余 | 8 | 不变 |

  裂片数还要乘以路引阶的系数。
- 棋盘上会生成“裂隙宝石”（特殊宝石），我方每匹配一颗 +3 裂片。
- 结果：速攻构筑在这个事件里收益更高；稳健构筑也能打，只是拿得少。

**稳定**

- 在关闭前打完全部裂隙节点，裂隙就会稳定：出现一群裂隙稀有怪（2 条词缀），并且 30% 几率出现“裂隙领主”。
- 稳定后必定掉落孵化胚。

### 3.2 押注点

- 为了评级打得更激进，还是保住生命？
- 时长快到了，还要不要冲最后一个节点？没打完，稳定奖励就没了。

### 3.3 专属货币与产出

- 裂片：撤离时转为永久物品“裂片”，失败则丢失。
- 孵化胚：刻印胚、路引胚、通货胚三种。

### 3.4 制作：孵化台（对应流放 2 的 Genesis Tree）

- 在营地放入孵化胚，消耗裂片，孵化出物品。
- 三种胚各有一棵小孵化树，点数来自累计消耗的裂片，可以免费重置。孵化树节点示例：
  - 指定标签权重 ×3（例如冰霜）；
  - 保证至少 4 条词缀；
  - 物品等级 +1；
  - 孵化路引时指定一条词缀的收益类别。
- 这是远征里唯一能“定向”做刻印的途径，所以裂隙在长期价值上很高。

### 3.5 首领链

1. 300 裂片合成一枚裂隙石。
2. 裂隙石转化为“裂隙要塞”路引：一张图里有三波连续裂隙，每一波的裂隙怪都会额外 +1 条词缀。
3. 击败裂隙之主，掉落孵化树的专属节点和史诗刻印胚。

### 3.6 放大旋钮

**罗盘**

| 罗盘 | 效果 |
| --- | --- |
| 一阶 | 1 只裂隙之手 |
| 二阶 | 裂隙时长 +3 步，裂隙节点 +2 |
| 三阶 | 再加 1 只裂隙之手 |
| 遗珍·速裂 | 时长 −3 步，裂片 ×2 |
| 遗珍·深渊之手 | 裂隙怪 +1 条词缀，孵化胚掉率 ×2 |

**星图 · 裂隙星群**

| 写法 | 节点 |
| --- | --- |
| 规则 | S 评级的回合数阈值 +1 |
| 规则 | 稳定后必定出现裂隙领主 |
| 规则 | 裂隙打开期间，冰潮暂停 |
| 代价交换 | 裂隙不再掉刻印，裂片 ×1.5 |

### 3.7 实现要点

- 评级依赖客户端上报的 `turns`，必须做合理性校验：和行动摘要、击杀数、法力事件数比对，异常时按 B 级处理。
- 裂隙宝石需要新增特殊宝石和战斗内经济键，做法和魔方的结晶宝石一样，两者可以共用一套实现。

## 4. 猎金（赏金狩猎）

原型有三个，各取一部分：

- 宝石战争的赏金活动：击杀悬赏目标得赏金点数；“赏金猎人”特质（`bountyhunter`，全库有 93 支部队带这条特质）会按部队的升阶稀有度给 2–6 倍赏金。
- 火炬之光的狩猎：先把关底首领强化，再让玩家选增益。
- 流放 2 的监督者石板：强化地图首领，换取首领掉落。

本作把它们合成一个“点名打首领、自己加码、连猎叠倍率”的事件。它同时承担“地图里要有更多首领级战斗”的需求。

### 4.1 局内玩法

**地图层：悬赏板与目标**

- 罗盘在外环生成一块悬赏板，上面挂 3 张悬赏。
- 每张悬赏是一名首领级目标，都从当前群系的独有首领和领主池里抽取（`03` §8），显示：
  - 名称、立绘、首领专属词缀；
  - 基础赏金；
  - 期限（步数）；
  - 位置：巢穴里的固定目标，或者在中环、内环游荡的移动目标。
- 最多同时接 2 张悬赏（星图可以加到 3 张）。
- 期限内没击杀，目标逃走，悬赏失败，不给赏金。

**追踪**

- 游荡目标每走 1 步，会在经过的节点留下“踪迹”，玩家能看到它最近 3 步的路径。
- 队伍里有野兽（Beast）部队时，踪迹显示最近 5 步，并预告它的下一步。
- 游荡目标每 2 步移动 1 次。追上它，或者在它的必经节点埋伏，都可以开战。

**加码（开战前）**

- 每名目标有 4 条可选的加码，例如：
  - 首领生命 +40%，赏金 ×1.3；
  - 护卫全部升为稀有，赏金 ×1.25；
  - 首领开局 30% 法力，赏金 ×1.2；
  - 首领多一个阶段，赏金 ×1.5。
- 最多加 3 条，倍率相乘。
- 加码在遭遇预览里选，选完锁定。

**战斗层**

- 目标战是一场首领级战斗：首领级单位 + 3 名护卫。多阶段首领用阵亡补位换成下一形态（`03` §8.4）。
- 赏金点数 = 基础赏金 × 加码倍率 × 连猎倍率 × 赏金猎人倍率。
  - 赏金猎人倍率：读出征队伍里带 `bountyhunter` 特质部队的升阶稀有度，按现有特质数据取 2–6 倍，取队伍里最高的一名。
  - 这让一批原本冷门的赏金猎人部队，在这个事件里成为真实的配队选择。

**连猎**

- 接连完成悬赏，中间不撤退、不全灭，连猎倍率每次 +25%，上限 +100%。
- 撤退或全灭后，连猎归零。

### 4.2 押注点

- 加几条码：加码越多赏金越高，但这场战斗也越容易输。输了等于一次全灭，扣命数，连猎归零。
- 要不要接第三张悬赏，来保住连猎倍率？
- 游荡目标是追上去打，还是绕到前面埋伏（更省步数，但可能扑空）？

### 4.3 专属货币与产出

- 赏金：结算成金币，以钱袋的形式放进背包，撤离后入账。这是远征里最主要的金币来源，也是王国 11–15 级的金币供给。
- 猎人徽记：每次完成悬赏获得，数量按赏金点数折算。撤离时转为永久物品。
- 目标专属掉落：每名首领级目标都有自己的掉落表，包括：
  - 它专属的传说或史诗刻印；
  - 它的首领铭文（首次击败时解锁，见 `03` §8.4）；
  - 本群系的高阶材料。

### 4.4 兑换：猎人公会（事件营地设施）

| 商品 | 作用 |
| --- | --- |
| 悬赏令 | 指定一名已经击败过的目标。下一趟的悬赏板上，必定出现该目标的悬赏，用来“点名刷”它的专属掉落 |
| 加码券 | 开战前免费加一条指定的加码，不占 3 条上限 |
| 追踪符 | 一趟内所有游荡目标的踪迹都显示 5 步 |
| 猎人等级 | 消耗徽记提升等级。等级越高，悬赏板上出现越高阶的目标，基础赏金也越高 |

### 4.5 首领链

1. 猎人等级达到 5 级后，每个赛季开放 3 张“传奇悬赏”。目标是各群系的传奇级首领，带固定的 3 条加码，不能撤销。
2. 每张传奇悬赏完成后，掉落一枚“传奇首级”。
3. 集齐 3 枚传奇首级，挑战“无面猎手”。它会复制你出征队伍中的 2 名部队，作为自己的护卫。

### 4.6 放大旋钮

**罗盘**

| 罗盘 | 效果 |
| --- | --- |
| 一阶 | 1 块悬赏板（3 张悬赏） |
| 二阶 | 每名目标多 2 条可选加码，期限 +4 步 |
| 三阶 | 再加 1 块悬赏板 |
| 遗珍·血契悬赏 | 所有目标强制带 1 条随机加码，赏金 ×1.8 |
| 遗珍·围猎 | 每张悬赏都变成双首领：两名首领级目标同场，赏金 ×2.5 |
| 遗珍·追猎 | 所有目标都是游荡目标，期限 −4 步，徽记 ×2 |

**星图 · 猎金星群**

| 写法 | 节点 |
| --- | --- |
| 规则 | 可以同时接的悬赏 +1 |
| 规则 | 赏金猎人倍率取队伍里两名最高者之和（上限 8 倍） |
| 规则 | 连猎上限 +50% |
| 规则 | 目标逃走时仍然给 50% 赏金 |

### 4.7 实现要点

- `bountyhunter` 特质现在的字段是 `onDelveBounty`，它的倍率在 meta 层读取，不进战斗引擎。
- 目标的移动、期限、加码在服务端保存。加码复用怪物词缀池和首领专属词缀。
- 首领级战斗的平均时长大约是普通战的 1.5 倍。一趟里如果打了 2 张悬赏加首领殿，就有 3 场首领战，要在模拟里单独统计这种情况的整趟时长。

## 5. 梦境

### 5.1 局内玩法

**地图层**

- 罗盘在内环生成一个“睡莲”节点。进入后开始下潜，梦境最多 6 层。
- 每一层是一场战斗，耗 2 步。梦境里不能休整，生命跨层延续。

**每一层**

- 敌人：所有敌人额外 +1 条“梦魇词缀”，并且全属性额外 +8%，逐层累积。
- 下潜前，可以从 2 条梦魇词缀里挑 1 条加给敌人。玩家自己挑代价，这个规则来自流放 2 谵妄。
- 泡影：
  - 第 1 层的泡影里有 2 件本阶物品；
  - 之后每下一层，泡影 +1 件物品，并把其中 1 件的品质提高一档；
  - 同时累积梦尘。

**每层胜利后选择**

- 醒来：泡影里的东西放入背包。
- 继续下潜：先显示下一层的噩梦概率——第 2 层 10%、第 3 层 20%、第 4 层 30%、第 5 层 45%、第 6 层 60%。

**噩梦**

- 判定为噩梦时，强制进行一场噩梦战（首领级，带 2 条词缀）。
- 胜利：泡影 ×1.5，然后醒来。
- 失败：泡影丢失，按常规全灭规则处理（扣命数、濒死撤回）。

### 5.2 押注点

每层的醒来或下潜，加上自选敌人词缀。这对应火炬梦魇和流放 2 谵妄的“再往前推一点”。

### 5.3 专属货币与产出

- 梦尘：分为三色，按层数和所选梦魇词缀产出不同的颜色。撤离时转为永久物品。
- 梦核：第 6 层或噩梦战胜利时掉落。

### 5.4 制作：灌注（对应流放 2 谵妄的灌注）

- 在营地用 3 份梦尘的组合（例如红红蓝），给一枚稀有以上的刻印写入一条“梦痕”。梦痕是额外的一行，不占词缀位，每枚刻印最多 1 条。
- 梦痕的内容来自白名单：现有的部队特质、职业天赋，这些都已经注册为动态特质。例如给一名输出部队灌注“匹配 4 颗以上时获得屏障”。
- 组合和梦痕的对应关系靠“配方簿”逐步发现：第一次用某个组合时揭示结果，之后永久显示。
- 梦痕可以把一名部队不具备的能力带进它的构筑，所以它是构筑深度的主要来源。白名单必须排除引擎“只取最强”字段上过强的条目，以及会改动经济的特质。

### 5.5 首领链

集齐 4 枚梦核：“梦主之门”路引。梦主战分 3 段，每段之间可以醒来或继续。击败梦主掉落专属梦痕配方。

### 5.6 放大旋钮

**罗盘**

| 罗盘 | 效果 |
| --- | --- |
| 一阶 | 1 朵睡莲 |
| 二阶 | 最大层数 6 → 8 |
| 三阶 | 再加 1 朵睡莲 |
| 遗珍·浅眠 | 噩梦概率 −40%，泡影升级速度减半 |
| 遗珍·沉眠 | 直接从第 3 层开始，泡影起点更高，噩梦概率 +10% |

**星图 · 梦境星群**

| 写法 | 节点 |
| --- | --- |
| 规则 | 第 4–6 层的噩梦概率 −10% |
| 规则 | 噩梦战失败时保留 30% 的泡影 |
| 规则 | 自选梦魇词缀的候选从 2 条变为 3 条 |
| 代价交换 | 泡影不再出刻印，梦尘 ×2 |

### 5.7 实现要点

- 噩梦判定由服务端抽定，客户端只看到概率。
- 梦痕通过动态特质注入，和刻印词缀一样走“合计后注入”的通道。注入前要检查“只取最强”字段的冲突（`04` §5）。

## 6. 金库

### 6.1 局内玩法

**地图层**

- 金库是 3–5 个节点组成的子区域，入口是金库门，需要金库钥匙。钥匙来源：宝库地精奇物，或者金库罗盘自带一把。
- 金库里有三种节点：保险柜（容器）、机关（陷阱）、守卫（战斗）。

**警戒值 0–100**

| 动作 | 警戒 |
| --- | --- |
| 打开保险柜 | +15–25（按保险柜大小） |
| 触发机关 | +20 |
| 守卫战 | +10 |

**警戒满 100：封锁**

- 金库门封闭。离开的办法：破墙（2 步），或者走秘道。
- 每 2 步刷一名增援游荡敌人。
- 金库里拿到的东西是普通背包物品，没带出就会丢。

**部队种族提供地图技能**

只看出征队伍里的部队，同一种族不叠加：

| 种族 | 技能 |
| --- | --- |
| 盗贼（Rogue） | 打开保险柜的警戒 −40% |
| 矮人（Dwarf）/ 构造体（Construct） | 拆除机关，警戒 +0 |
| 野兽（Beast） | 嗅出暗格：每个金库多 1 个隐藏保险柜 |
| 机械（Mech） | 黑入警报：每趟一次，警戒 −30 |
| 神圣（Divine）/ 秘术（Mystic） | 驱散诅咒保险柜的诅咒 |
| 精灵（Elf）/ 妖仙（Fey） | 潜行：守卫战 50% 几率可以绕过 |

这让 1800 支部队的种族在地图层也有意义：为了刷金库，玩家会带不同的阵容。

**战斗层**

- 守卫带“警觉”词缀：战斗超过 N 回合后，每多 1 回合警戒 +5。
- 结果：在金库里打得越慢，越危险。

### 6.2 押注点

- 警戒还剩 20，要不要再开一个大保险柜？
- 是在警戒满之前离开，还是接受封锁，再破墙出去？

### 6.3 专属货币与产出

- 金库币：撤离时转为永久物品。
- 蓝图：稀有掉落。

### 6.4 兑换：金库商（事件营地设施）

用金库币购买指定记忆的指定编号碎片（`07`），包括各张塔罗牌、诅咒符文、宝珠对应的记忆碎片，按记忆品质定价。这样玩家可以用金库补齐最后几块。金库就是熔炉文档里“地精宝库”这条长期材料来源在本作的实现。

### 6.5 首领链

1. 蓝图转化为“大金库”路引：3 个翼区，警戒全局共享，玩家选择劫哪几个翼区。
2. 最终挑战“金库主人”，掉落专属塔罗牌和史诗刻印。

### 6.6 放大旋钮

**罗盘**

| 罗盘 | 效果 |
| --- | --- |
| 一阶 | 1 座金库，附带钥匙 |
| 二阶 | 保险柜 +2 |
| 三阶 | 再加 1 座金库 |
| 遗珍·重宝 | 保险柜品质 +1，警戒增长 +30% |
| 遗珍·内应 | 警戒上限 150 |

**星图 · 金库星群**

| 写法 | 节点 |
| --- | --- |
| 规则 | 封锁后的增援间隔 +1 步 |
| 规则 | 保险柜 10% 几率复制内容，但这一次额外 +10 警戒 |
| 数值 | 金库币 +25% |
| 代价交换 | 保险柜不再出刻印，记忆碎片 ×1.5 |

### 6.7 实现要点

- 种族判定直接读 `troopTypes`。
- “警觉”依赖上报的 `turns`，和裂隙一样要做校验。
