# 深渊远征 · 记忆残片与熔炉材料

日期：2026-10-28。状态：提案，未实施。

## 0. 定位

- 宝石战争熔炉相关的材料（各类宝珠、宝石、龙晶、塔罗牌、诅咒符文等）不在远征里直接掉落。远征掉的是“记忆残片”。
- 一组残片拼成一份完整的“记忆”，使用后随机获得少量对应的熔炉材料。
- 残片可以在交易行流通；拼好的记忆和开出来的熔炉材料都是绑定的。这同时满足两条：熔炉材料可以间接交易，主线材料本身不上交易行。

原型是火炬之光：无限的“记忆荧光”：约 32 套，集齐指定张数后到 NPC 那里换固定奖励；有全域掉落，也有按位面、按玩法限定的掉落；罗盘、探针、荧光哥布林可以提高产量（见 `research/` 和子 agent 调研）。

本作在这个基础上加了两点：

- 拼图：每份记忆由固定位置的碎片组成；
- 忆境：拼好之后可以选择进入一场谜题战斗，提高开出来的收益。

这让记忆残片本身也成为一种玩法，而不只是收集物。

## 2. 记忆的结构

### 2.1 套与拼图

- 每份记忆对应一类熔炉材料，例如“智者的低语”对应智慧宝珠。
- 每份记忆是一张图，切成固定数量的碎片，每块碎片有自己的编号：

| 记忆品质 | 碎片数 | 拼图 | 产出（示例：智慧宝珠） |
| --- | --- | --- | --- |
| 精良 | 4 | 2×2 | 普通智慧宝珠 1–2 |
| 稀有 | 6 | 2×3 | 普通 2–3，10% 几率高级 1 |
| 传说 | 9 | 3×3 | 普通 3–5，25% 几率高级 1 |
| 史诗 | 12 | 3×4 | 高级 1，另有 40% 几率再 1 |
| 神话 | 16 | 4×4 | 指定稀有物，例如某一张塔罗牌，或力量宝珠 |

- 掉落的是某一份记忆的某一块编号碎片，例如“智者的低语 · 碎片 5/9”。
- 同一块碎片可以重复获得。

### 2.2 重复碎片的处理

- 交易：碎片可以上交易行（可堆叠物品，按“记忆 + 编号”区分）。
- 置换：在营地的“忆匠”那里，3 块同一份记忆的重复碎片换 1 块随机的、你还缺的碎片。
- 分解：拆成“忆尘”，用来买指定编号的碎片，价格很高，用来兜底最后一块。

### 2.3 首批记忆表（设计值）

| --- | --- | --- | --- |

## 3. 忆境（让拼好的记忆变成一种玩法）

拼好一份记忆后有两种用法：

1. **直接唤醒**：立即按 §2.1 的表获得材料。
2. **进入忆境**：一场固定的谜题战斗。
   - 谜题由三条规则组成：
     - 固定的敌人（来自这份记忆的主题）；
     - 开局预置的特殊宝石（`rules.board.preset`）；
     - 回合上限加击杀目标（`turnLimit` + `objective.killTargets`）。
     
     例如：“6 回合内击杀两名指定敌人”。
   - 谜题使用玩家自己的队伍和刻印。
   - 成功：产出 ×2，并且高级品的几率翻倍。
   - 失败：记忆不消失，可以再试或改为直接唤醒，但每次失败都消耗一点“忆尘”。
   - 每份记忆有 3 个预设谜题，按品质轮换。谜题由人设计，目标是“想清楚再走”，而不是数值碾压。

这些规则引擎都已经支持：`BattleRules` 里有 `board.preset`、`turnLimit`、`objective.killTargets`、`turnStart.createGems`。完整的固定盘面（逐格指定宝石）现在不支持，需要新原语；首期只用预置特殊宝石。

## 4. 产量旋钮（参考火炬的荧光罗盘、探针、荧光哥布林）

| 手段 | 效果 |
| --- | --- |
| 忆光罗盘（`01` §2.2 新增一种通用罗盘） | 本趟记忆碎片掉落 +40%；遗珍版“聚光”：限定碎片 +50% |
| 残片地精 | 稀有奇物，每趟 3% 出现；追上并击败它，掉落 8–12 块碎片 |
| 星图节点 | 例如“碎片 15% 几率复制一块”“首领必掉 1 块本群系限定碎片” |
| 委托 | 周委托奖励指定记忆的碎片 |
| 宠物（`08` §2.2） | 鼹鼠：矿脉可以再挖一次，5★ 时再挖至少出 1 块碎片；松鼠 5★：矿脉显示会出哪一种记忆的碎片 |

每张地图和每个首领的限定碎片，在情报页（U12）和地图台汇总里都能查到，玩家可以按需要刷。

## 5. 交易与绑定

| 物品 | 交易 |
| --- | --- |
| 记忆碎片 | 能。按“记忆 + 编号”分开挂单，走订单簿；受带出标记约束（`06` §3） |
| 拼好的记忆 | 不能 |
| 唤醒得到的熔炉材料 | 不能，直接进主线材料库存 |
| 忆尘 | 不能 |

## 6. 结算

- 碎片是远征物品：战斗和搜刮得到时进背包，撤离时入账，显示在撤离结算页。
- 唤醒记忆和完成忆境不属于远征的局，但同样要显示真实获得：结果弹层逐项列出材料的名称和数量，按操作 ID 幂等。
- 忆境本身是一场战斗：结算页的“本场实际获得”列出唤醒得到的材料。失败时只显示消耗的忆尘，不显示任何获得。

## 7. 实现要点

- 新增主线材料库存：宝珠（按种类和普通/高级）、宝石珠（六色）、碎片、钻石、龙晶、塔罗牌（逐张）、诅咒符文、召唤水晶。这和熔炉文档“先引入带 `outputKind` 的配方及库存交易”是同一件事。
- 新增远征物品类型：记忆碎片（记忆 ID + 编号），以及忆尘。
- 熔炉文档里“部队移池”的前提——全套材料都能稳定获得——由记忆提供长期来源。上线前，要按产量模拟核对每张塔罗牌的期望获取周期。
