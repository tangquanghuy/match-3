# 第一版远征策划审计记录（2026-10-28）

审计对象是第一版的四份文档（已被本目录下的第二版取代）。这份审计由独立子 agent 完成，并对照了代码：`encounter.ts`、`opponentTeams.ts`、`roleComps.ts`、`engine/traits.ts`、`TurnEngine.ts`、`towerTraits.ts`、`regionalPvp.ts`、`troops.json`。本文按问题汇总，每条后面写明第二版怎么处理。

## A. 凑数与浅层内容

| 问题 | 结论 | 第二版处理 |
| --- | --- | --- |
| 噪音系统 | 按文档自己的数值，噪音每步衰减 1，阈值 3 基本到不了，猎手、噪音格全部空转 | 删除噪音 |
| 光照 | 是全套系统的支点，却没有给出任何公式；文档还引用了不存在的章节 | 改为“灯火”，写成完整公式（玩法 §3） |
| 10 条群系地图机制 | 本质都是“图边 ±1–2 步”，不碰战斗、不碰构筑、没有奖励循环 | 全部删除；真正的玩法改由“地图事件”承载（地图事件文档） |
| 星盘 | 只是威胁×奖励的滑条，和火炬罗盘、流放 2 路石只有名字相同 | 改为“路引（玩家自制地图词缀）+ 罗盘（插入地图事件）”（玩法 §2） |
| 奇物事件 | 约一半没有选择、没有代价 | 重写，每个选项都有代价（玩法 §6） |
| 营火、灵契 | 存在被压制的陷阱选项 | 营火改为三选一，每个选项有明确定位；灵契改名为“遗物”并去掉陷阱项 |
| 参考表 | 11 款游戏、每款一个机制名，属于背书式凑数 | 删除；参考只在具体机制里写明来源和差异 |

## B. 核心循环

| 问题 | 结论 | 第二版处理 |
| --- | --- | --- |
| 时钟 | 只是第六个资源条；撤离窗口和威胁到来时间开局就可见且确定，整局退化成背包问题；最优解是早撤 | 压力来源改为地图事件内的押注，以及灯火越低收益越高；入账倍率随深入程度提高（玩法 §3.4）；资源条只保留步数、灯火、命数、背包 |
| 全丢与刷子冲突 | 做过的装备不可再生，理性玩家要么不带好装备，要么穿高装刷低深度 | 保留“失败全丢”的裁定，同时三项缓解：一是引入“命数”（仿火炬 6 次挑战），全灭只扣命数，命数耗尽才真正失败；二是刻印的长期价值主要沉淀在铭文库（不会丢），丢掉的实例可以用已录的铭文铭刻回来；三是收益按路引阶陡峭增长，材料和物品等级都随阶提高，所以穿着高阶装备刷低阶并不划算。模拟时需要验证第三点 |
| 投保 | 规则自相矛盾，费用也没定义 | 只保留保险格；给已穿戴的刻印投保等于占用一个保险格 |
| 烟雾弹 | 太便宜，可以连续规避遭遇 | 每趟最多携带 1 个，使用耗 1 步 |
| 断线 | 按撤退处理会惩罚移动端的网络波动 | 断线后可以重开这场战斗，代价是消耗 1 命数 |

## C. 敌人设计

| 问题 | 结论 | 第二版处理 |
| --- | --- | --- |
| 阵容模板 | 5 个模板按 role 组队，比现有代码倒退：`buildAdaptiveDefense` 能从全池 1800 支部队抽样并做协同评分，`ROLE_COMPS` 已有 10 个按“卡实际作用”筛选的模板 | 全池抽样，附加群系谓词；新增怪物稀有度和词缀体系（敌人文档） |
| 引擎“取最强、不叠加”的字段 | 包括闪避、反弹、开局法力、无视护甲、偷法力、屠戮倍率、`selfRevive`、各类召唤、`inflictOnSkullHit`（只保留回合最长的一条） | 词缀生成时检查字段冲突，冲突就换一条；多条状态改用 `inflictOnSkullHitList` |
| 重复特质码不去重 | 累加类字段会翻倍，按 code 结算的回合开始改棋盘类会多次掷骰 | 刻印和怪物词缀都按合计值离散化后，每种只注入一条 code |
| 召唤 | 召唤只能进空位，敌方 4 人满员时“开局召唤增援”永远不生效 | 增援改为 `summonOnDeath` / `summonOnAllyDeath`，在阵亡后补位 |
| 复活 | 设计稿把“不屈”列为需要新原语 | `selfRevive` 已实现，直接使用 |
| 开局风暴 | 先左方后右方结算，后来者顶替；敌方风暴会静默覆盖玩家的开局风暴 | 遭遇预览中显示“风暴冲突” |

## D. 数值

| 问题 | 结论 | 第二版处理 |
| --- | --- | --- |
| 共鸣 | 槽位限制导致元素类标签到不了 6/9 档，而通用属性标签随手就到 9 | 三个刻印位改为通用槽；属性词缀不带标签；逐个标签验算可达性 |
| MF 取舍 | 约 1% 战力换 +25% 稀有度，几乎没有取舍 | 搜刮词缀自带绑定代价（仿流放 2 路石词缀） |
| 精通 | 设计稿给出的 63–66% 计算有误；全局削减后又在远征里卖回来，影响全模式 | 精通削减按用户裁定保留；删除“远征精通”词缀，不再卖回 |
| 通配宝石 | 产出通配宝石的词缀累加没有上限，会滚雪球 | 设上限，全队合计 |
| 敌方倍率 | 多项倍率叠加没有总上限；法术伤害没有单独曲线 | 设总上限；魔法单独一条曲线 |
| 产出缺失 | 永生余烬、洗印石没有来源 | 补齐来源表 |
| 王国 11–15 级 | 金币成本过高 | 下调 |
| 其他不一致 | 橙色潜能值低于黄色；深潜首领是否必掉传奇前后冲突；坐标获取说法不一致 | 修正 |

## E. 界面

- 战败流程跳过了战斗结算页，违反 AGENTS.md。已修正：任何战斗都先进入战斗结算页。
- 首领变体首杀这类永久解锁，入账时点没有写明。已写明：在战斗结算时入账，并显示在“本场实际获得”。
- 钱袋折算规则缺失。已补：战斗内收集的金币和灵魂按实际值折算成钱袋，显示在“放入背包”。
- 移动端出现双底栏，HUD 过载。已修正：远征内隐藏外壳底栏，HUD 默认折叠。
- 补齐了缺失的状态：周轮换、断线、暂离、仓库满、镜像池为空等。

## 用户后续裁定（第三版）

- “失败全丢”不作为风险处理，全丢保留。第四版中，遗失刻印进入不对玩家展示的后台失物池，以随机重现或寻回罗盘的方式找回（`01` §5.1）。
- 遗迹事件删除，换成猎金（`02` §4）。
- 地图里增加首领级战斗（`03` §9）。
- 群系差异化靠独有敌人、领主和首领（`03` §8）。
- 刻印品质改为沿用部队的六档稀有度。审计 F 节里“品质名和部队稀有度撞名”这一条不再采纳。
- 新增通货与交易行（`06`）。

## 后续裁定（第四轮，2026-10-29）

- 灯火（明亮度）取消，改为冰潮：步数只在服务端记，玩家看到的是冰潮按时一批批封住区域，最后一次冰潮时还在图里算失败（`01` §3.1–§3.2，`12` §2.2）。上文提到灯火的结论保留原样，作为当时的记录。
