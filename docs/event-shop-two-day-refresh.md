# 活动商店每两天补货（2026-09-25）

## 规则

- 六家活动商店统一使用连续的两个本地自然日作为一期，于当地时间零点补货。锚点为2026年1月1日；不是登录后计时，也不在周一重新起算。
- 例如2026年9月24日零点至26日零点为一期，下一期截至28日零点。9月20日与21日在同一期，跨周不额外补货。
- 限购数量每期恢复，材料货品保留，精选角色从原主题候选池按期轮换；仅有一个候选时仍会重复。主题固定取本期起始日所属周，保证期内货架稳定。
- 价格、单期库存和每活动每周360印记获取上限不变。更频繁补货增加兑换机会，但不额外发放印记或宝石；玩家仍需分配周预算。
- 补货不清印记或活动进度。活动进度、宝石奖励领取状态与印记仍按原规则在周一零点重置。

## 状态与交互

- `EVENT_SHOP_REFRESH_DAYS` 为周期配置，`eventShopPeriodOf` 统一计算周期，按自然日计算以避免夏令时日长差异。
- 存档新增独立的 `eventShops` 库存账本；周购买记录保留为累计历史，不再决定剩余库存。
- 旧存档首次访问时继承当周已购数，避免升级后立即重复领取；下一期正常补满。跨周、跨多期离线、重载均按当前周期解析。
- 倒计时、售罄提示与规则文案同步更新。页面到点自动刷新，重新聚焦或恢复可见时补检。
- 旧货架的兑换、物品详情和图鉴点击先校验周期；跨期先更新货架，不使用旧按钮误兑新角色。兑换接口也校验预期周期。
- 现有分类筛选、角色图鉴入口与返回商店行为保留。
