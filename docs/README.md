# 文档目录

项目文档按用途分为三类：

- 当前规范：直接约束实现或验收的文档，例如 `battle-settlement-rewards.md`。
- 研究与发布记录：按日期记录已经落地的设计、调参和线上核验。
- `archive/`：已经退出执行的总计划和并行协作台账。它们保留历史背景，不作为当前任务入口。

当前没有登记中的长期任务；新任务入口为 [`../tasks/active/`](../tasks/active/)。旧任务书位于 [`../tasks/reference/`](../tasks/reference/)，不会自动重新启用。

SillyTavern 通用战斗：

- [`sillytavern-original-requirements.md`](sillytavern-original-requirements.md)：保留最初接入构想的用户原话，作为后续设计基准。
- [`sillytavern-product-plan-audit.md`](sillytavern-product-plan-audit.md)：独立上下文对原始需求和产品任务书的可实现性审核。
- [`sillytavern-battle-product-plan.md`](sillytavern-battle-product-plan.md)：当前产品设计提案，包含按法力颜色/稀有度/五形态/现有职责设计敌人、族群联动、技能通用化、原始跑图提示词打标与真实立绘装配、魂片与武器成长、本地存档和分期验收；立绘离线索引已实现，宿主战斗接入待实现。
- [`sillytavern-progression-bridge-research.md`](sillytavern-progression-bridge-research.md)：现有代码与酒馆变量的接入调研，含旧跑图提示词的全量结构、资源关联与同名/改名盘点；产品与交付范围以产品方案为准。
- [立绘形态标注与四维筛选](portrait-forms.md)：1800 项首轮形态标签、五类判定口径、稀有度映射、现有职责复用、精确查图与维护命令。
