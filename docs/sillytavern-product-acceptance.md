# SillyTavern 首版产品验收清单

日期：2026-10-21。依据：[任务书](sillytavern-battle-product-plan.md)、用户已确认规则。每行以玩家实际操作、可见反馈、持久化结果共同验收。未完成真实酒馆试玩的项目保持待验。

| 页面/场景 | 操作及预期结果 | 验收证据 |
| --- | --- | --- |
| 初次启用 | 显示当前聊天和空槽，创建后只绑定该聊天；刷新打开同档 | 当前聊天 ID、槽位 ID、刷新前后截图 |
| 槽位已满 | 第四个聊天显示三个已绑定聊天及手动删除入口；玩家明确删除后释放一个槽位 | 三档未被自动覆盖；删除仅作用选中档 |
| 切换聊天 | 已绑定聊天打开对应档；新聊天创建新档；复制聊天得到新 ID 后独立建档 | 颜色、图鉴、学习、淬炼均按档隔离 |
| 遇敌卡 | 四维条件对应真实肖像；显示敌人数、编号、职责、稀有度、威胁；未确认前允许编辑 | 固定蓝图和候选编号 |
| 肖像筛选 | 六色完整集合、五稀有度、五形态、既有九职责联动；空组合显示原因与清空条件操作 | 不静默换颜色、形态或职责；保留明确选择 |
| 肖像选择 | 保存后刷新仍是同一图片与配置；数据变更导致失效时提示重新选择 | 图像哈希与资源 ID 一致 |
| 技能组装 | 显示目标、消耗、数值、条件、被动与依赖；缺失绑定不能被算作已完成覆盖 | 每一原始稀有度及五档适用敌人均至少 90% |
| 战前准备 | 展示 1–4 名固定同行者；每人一个主动；主角武器主动，同伴基础或已学能力；开战冻结快照 | 后台装备变化不改变正在进行的战斗 |
| 无武器主角 | 使用 Common 骑士之剑 gw_KnightsSword，蓝色、3 法力；叙事背包无需新增道具 | 配置来源与真实武器库一致 |
| 同伴颜色 | 读取酒馆角色变量；首次分配落盘；刷新、描述变化、开关页面均不重抽 | 同一稳定角色 ID 前后颜色相同 |
| 颜色兼容 | 能力颜色集合须为同伴固定颜色集合的子集；不兼容显示所缺颜色 | 收藏和学会不要求当前存在可装配者 |
| 战斗 | 可检查双方主动与被动、HP、护甲、法力；合法行动确认后保存；刷新恢复到最近确认行动 | 同种子、同配置、同行动恢复一致 |
| HP 模式 | 剧情沿用酒馆当前 HP/临时 HP；开战显示换算；只在结算同步；再现独立满血 | 不重复计算装备面板，不在两种面板模式间混算 |
| 剧情胜利 | 只认三消胜利；记录实际击败对象、我方倒下及复活、初末 HP 和百分比 | 战报逐项可追溯到行动日志 |
| 失败/中止 | 显示真实战果和 HP 变化；不解锁图鉴、不累计魂片；中止入口说明后果 | 失败与中止状态独立，不误判胜利 |
| 本场结算 | 所有实际入账的物品、材料、货币显示真实名称和实际数量；无收益也有明确反馈 | 发奖明细、存档余额、可见结算卡逐项一致 |
| 重复提交 | 同一战斗只入账一次；结算页重开保持原结果；同步待确认可重试 | 不重抽奖励，不重复累计首胜/魂片/材料 |
| 队伍页 | 只编辑当前存档队伍，最多四名；看得到颜色、主动来源及兼容状态 | 开战前校验，返回保留编辑结果 |
| 图鉴 | 仅剧情三消获胜后收录；保留整场敌方阵容及配置；未击败对象不伪造战果 | 失败、AIRP 胜利、再现均不新增剧情图鉴 |
| 魂片 | 首次剧情胜利计入；每场每个实际击败的独立未学来源 +1；同源多只去重 | 20/14/10/7/5 基线按来源稀有度累计 |
| 先收藏 | 无同伴、无颜色兼容者时仍正常获得魂片、学会、展示进度 | 不阻止开战或领奖 |
| 同能力来源 | 任一来源学会实际能力后，本档现有及未来相同能力来源均显示已学会 | 以实际能力代码去重，不以名称或肖像去重 |
| 往昔再现 | 重复原整场敌方配置、位置、等级、技能与难度；我方当前队伍独立满血 | 不重抽敌人，不改酒馆 HP、临时 HP、经验、剧情 |
| 再现结算 | 只产生未学能力魂片；失败不增长；全部学会后关闭挑战，仍可查看图鉴/旧战斗 | 无重复养成材料、经验、里程碑或首胜奖励 |
| 武器与淬炼 | 查看真实武器能力和材料余额，提交前展示成本与增益；同能力代码共享进度 | 扣费与成长原子保存；战斗产物仍在本场结算显示 |
| 战报 | 展示胜败、击败名单、倒下及复活、初末 HP/百分比、净变化；累计伤害/治疗另列 | 报告由已保存事实生成；重试报告不改战果 |
| 同步失败 | 本地结果先保存；显示待同步/失败原因及重试；确认后更新状态 | 刷新不丢结果；冲突不覆盖更新的聊天变量 |
| 存档管理 | 导出选中档，导入校验版本与聊天绑定，手动删除选中档 | 不悄悄迁移聊天绑定；三档上限保持 |

## 首轮数值基线与标定记录

| 字段 | 基线 | 验收方式 |
| --- | --- | --- |
| 魂片有效胜利次数 | 杂兵20、精锐14、首领10、领主7、传奇5 | 边界逐次累计；首胜包含在内 |
| 队伍人数 | 1–4 | 同配置检查人数差异，不用假队友补足 |
| 适配覆盖门槛 | 每个原始稀有度 ceil(适用数 × 90%)；另附五档汇总 | 按敌人条目统计；有证据的特殊依赖才排除 |
| 面板样本 | 1、10、20、49、50、95级；经典/新面板模式 | 记录初始 HP/攻击/护甲/法强与换算版本 |
| 战斗体验 | 首轮记录耗时、有效行动数、双方施法次数、胜率、伤害与治疗 | 真实试玩数据出炉后决定调值，不虚构达标区间 |
| 主动预算 | 每名一个主动；保留真实消耗与效果，数值按版本化转换 | 预览说明、实际日志与最终快照一致 |

## 验收记录规则

页面状态以自动化回归与真实试玩分别记录。数据索引、注册、烟雾执行、通用上下文绑定、完整组装验收分开报告；前四者均不自动等于最终产品覆盖通过。真实酒馆尚未验证时记录具体缺口，继续推进独立工作。
