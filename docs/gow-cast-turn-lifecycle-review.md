# 施法消耗回合：真实管线修复

## 2026-09-27 用户裁定

普通施法消耗回合，覆盖此前免费施法约定。修复作用于 TurnEngine 统一施法入口，部队、武器、自设角色均复用，不只改界面文案或 activePlayer。

- 合法施法：扣除法力、执行技能、完成爆破队列、判定胜负，随后复用 finishTurn。
- 普通施法：交接行动权；执行即将行动方的再生、回合开始特质、状态伤害/提前解除/到期、风暴递减和死局检测。
- 额外回合：在当次施法消费信号，保留行动权，触发额外回合特质；沿用项目现有约定，不重复结算真实换手的回合开始效果。后续普通施法/交换正常换手。
- 冻结：仍可施法、骷髅攻击；关联颜色的大匹配、第一存活部队冻结的骷髅大匹配、被冻结施法者自身的法术额外回合分别抑制。未冻结的其他盟友施法仍能获得额外回合。
- 非法施法、缺蓝、沉默、阵亡、错误阵营、解析态输入、分支取消：无扣蓝、无日志、无回合结算。
- 致胜技能立即结束；换手后的状态伤害致胜则将本次行动日志更新为 game-over。
- held 只兼容旧日志，新施法日志生成 switched / extra-turn / game-over。

## 验证

专项文件：tests/unit/castTurnLifecycle.test.ts，42项，覆盖双方、连续施法、状态伤害、再生、风暴、技能与匹配额外回合、额外回合特质、冻结、取消、胜负。

既有真实技能测试继续检查原有伤害、目标、耗蓝与条款，同时更新旧免费施法假设：

- 火枪手7004、两把前两敌伤害武器、Lianka和施法日志：普通施法换手。
- 7412 Mana Burn：直接伤害金额保持不变，最终生命另计真实换手后的燃烧结算。
- Burning Scythe：分别检查燃烧/疾病施加事件，保留不同目标约束；状态允许在对方回合开始提前解除。
- 战后经济用例：两次盟友施法之间加入真实对手 passTurn，不跳过行动权。
