# 任务书目录

任务书按当前执行状态归档，避免把历史审查或已取消窗口误当成进行中的实施要求。

## 当前执行

`active/` 是当前可以继续推进的任务书。总纲和实时状态见：

- `active/TASK-MASTER-PLAN.md`
- `active/TASK-UX-PHASE-B.md`
- `active/STATUS.md`

## 参考与归档

`reference/` 保存已经完成阶段、被取消窗口或仍需作为设计依据的文档，不作为当前实施任务派发。

## 更新规则

每个实现批次完成后，必须同步更新对应 `tasks/active/TASK-*.md` 的工作记录、验证证据和剩余项；若用户口径覆盖旧方案，保留历史记录但在文档顶部明确标记 superseded。
