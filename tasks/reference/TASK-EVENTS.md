## 3. 验收标准

1. 六活动页**全部可玩**，无预告态；六卡总览可点进、角标准确。
2. **进度不串号**：在 A 活动攒分不影响 B 活动的里程碑/代币/已购（单测锁）。
3. 打完活动战**回到原活动页**（E-10 断言）。
4. 六个专属状态区**全部有图形**：每页 `img/canvas/svg/[data-icon]` 计数 > 0（复跑 `u4-events.mjs`，原始值为 0）；塔层页要能看到四个成员的残血。
5. 商店在**独立页**且从活动页/总览/结算三处都能进；售罄与买不起两态形态化可分辨；购买后持有量就地变化。
6. 周期告知：真倒计时 + "重置会丢什么"（代币作废/限量刷新/积分清零）在页面上说清（E-8、S-4）。
7. 门槛全绿 + 22 条清单通过 + 改前/改后对照截图（六活动页各一张 + 商店页）。
