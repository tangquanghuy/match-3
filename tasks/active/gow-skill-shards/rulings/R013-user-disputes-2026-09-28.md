# R013 用户裁定的一批来源争议（2026-09-28）

1. **1/4、1/2 法力一律向下取整**（L3-005）。「给予四分之一／一半法力」= floor(目标法力上限 × 比例)。
2. **随机法力全体共用一次掷骰**（L3-013、troop:7465 L1-E-7465-random-mana-dispute）。一次施法里「给所有盟友随机 X–Y 点法力」只掷一次，所有目标得到同一个值。
3. **weapon:1203 = 另一个随机敌人**：第二次命中优先选与上一目标不同的敌人（RandomPrefNotPrev），只有场上没有其他存活敌人时才打回同一人。以英文为准，不用原生的普通 RandomEnemy。
4. **weapon:1404 只按黄宝石计数**：治疗加成只看黄宝石，不累加前一步的紫宝石计数（以英文为准）。
5. **「移除／摧毁所有宝石」包含骷髅及其全部变种**（L3-remove-all-skulls：7287、7137）。骷髅也是宝石，末日骷髅等变种同样算骷髅：
   - 「所有宝石」类清屏不能留下任何骷髅／末日骷髅。
   - 按颜色移除骷髅（如僵尸 troop:6052 RemoveColor Skull）同时清掉末日骷髅等骷髅变种。
   - 移除（remove）仍遵守 R010：不给法力、不触发特殊效果；摧毁（destroy）照常触发。
