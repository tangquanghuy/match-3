# R010 移除宝石会触发特殊宝石效果（用户裁定，2026-09-28）

取代此前 sa-P 的提议。

- 原生 `RemoveColor` / `RemoveGems`（英文 “Remove … Gems”）移除的宝石中如有特殊宝石（炸弹、末日骷髅、法力药水、宝箱、各类状态宝石等），**照常触发它们的特殊效果**，与被摧毁时相同。
- 普通宝石的规则不变（P-F1-remove-gems 已实现）：移除不给法力、骷髅不造成伤害、不产生资源；被移除的宝石计入“因被移除的宝石数而增强”；棋盘照常补充和连锁。
- 特殊宝石效果本身引发的后续（例如炸弹爆破其他格、末日骷髅爆炸伤害）按该宝石自身规则结算。
- 实现：`TurnEngine.resolveBoardChange` 对 `remove` 模式也执行特殊宝石摧毁链（`expandSpecialDestruction`），但被“移除”本身波及的普通宝石仍不给法力、骷髅仍不伤害；由特殊宝石效果二次摧毁的格按普通摧毁结算。
