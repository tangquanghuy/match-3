### 重设计提案

#### P0 · B-4 + B-3 + B-6：施法流程三段式（附录 A 阶段 3 遗留项的落点）

现在是「满法力 → 短按 → 直接进选择层/直接结算 → 特效 → 无字」。提案补两端：**放之前看得懂，放之后知道发生了什么**。

```
① 可释放提示（B-6）                ② 确认层（B-4）                        ③ 效果摘要（B-4）
┌──────────┐                ┌────────────────────────────────┐   ┌──────────────────────────┐
│ [立绘]    │                │ 潮汐之愈            法力 12/12  │   │ 潮汐之愈                  │
│ ◈ 满! ←流光│  ── 短按 ──→   │ 治疗一名盟友 [魔法+5 = 14] 点   │   │ · 奥契丝 +14 生命          │
│ 8⚔ 3🛡 9♥ │                │ 生命，并给予屏障。              │   │ · 奥契丝 获得 屏障（1 回合）│
│ 法力 12/12│← B-2 常驻数字   │ 目标：奥契丝（高亮闪烁）        │   └──────────────────────────┘
└──────────┘                │  【 释 放 】      【 取消 】     │    ↑ 棋盘上方 2.5s 后淡出，
  法力未满时短按 →           └────────────────────────────────┘      可在 HUD 里回看最近 3 条
  「还差 6 点法力」浮窗 + 卡片摇一下（B-3）
```
三条规则：
1. **确认层是可关的**：设置里给「跳过技能确认」开关（老玩家会嫌慢），但**默认开**——因为法力是跨回合积累的资源，误触代价高。
2. **确认层里的数字必须是求值后的**（`[魔法+5 = 14]`），复用 `shell/spellText.ts` 的 `renderSpell(desc, magic)`，与英雄页/图鉴同一套渲染。
3. **效果摘要条**逐条列本次释放的实际结果（伤害/治疗/状态/召唤），数据来自 `session.resolve` 返回的事件流——事件已经在手（`App.ts:2725 const events = this.session.resolve(...)`），只是没有被翻译成人话。

### 五问自查

1. **3 秒问题**：**过关**。三秒内能看出这是三消战斗、哪边是我方、现在第几回合——棋盘占据绝对主视觉，左右卡列分明，`TURN 01` 横幅居中。这是全仓 3 秒问题回答得最好的一屏。不过关的是"我现在能做什么"：除了拖宝石，卡片可点这件事没有任何提示（B-5），可释放态只有 18% 亮度差（B-6）。
