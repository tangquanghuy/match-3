### 重设计提案

#### P0 · M-1 rail 入口重排（线框）
地图左右两列不该是"7 个一模一样的菱形"，应按**"现在能做" / "以后能做"**分层，并且**不存在点了没反应的按钮**：

```
左列（玩法 · 按推进顺序，自上而下）      右列（养成 · 三项，与底部主导航不重复）
┌──────────────┐                        ┌──────────────┐
│ ◆ 王国任务    │← 主推荐：带进度环      │ ◆ 武器库      │→ #hero 武器区锚点
│   破碎尖塔 1/8│   与金色呼吸光         │   已装备 3/6  │
├──────────────┤                        ├──────────────┤
│ ◆ 战役        │                        │ ◆ 神殿        │→ #hero 职业区锚点
│   第 2 章     │                        │   可进阶 1    │
├──────────────┤                        ├──────────────┤
│ ◆ 世界事件    │← 有未领奖励时角标      │ ◆ 馈赠        │→ #chests 每周礼遇
│   6 个进行中  │                        │   今日可领    │
├──────────────┤                        └──────────────┘
│ ◇ 入侵  Lv.10 │← 锁态：菱形去金改石灰
│   还需 9 级   │   + 明确差多少级
└──────────────┘
```
规则三条：
1. **每个入口必须有落点**。没有目标屏的项（战役）不上 rail，或降级为锁态菱形 + 「Lv.x 开放」文案，点击给一句明确的"还没开放"。
2. `.on` 高亮只给"当前最该点的那个"，且它必须是可用的；不可用的项一律走灰石样式（区别要大到不看文字就能分辨）。
3. 每项第二行副题从"分类描述"（章节战斗/更换装备）换成"**当前状态**"（破碎尖塔 1/8、可进阶 1、还需 9 级）——这是玩家真正要的信息。

#### P0 · M-2 节点徽章拆成两种形态（线框）
同一个槽位承载相反语义是根因，拆开：

```
已解锁节点                        锁定节点
   ┌──────┐                         ┌──────┐
   │ 彩色 │  ← 纹章正常上色         │ 石灰 │  ← 纹章去色 + 压暗（已有）
   │ 纹章 │                         │ 纹章 │
   └──────┘                         └──────┘
 ┌──────────┬────┐               ┌──────────────────┐
 │ 破碎尖塔 │ Lv3│               │ 🔒 冒险者 Lv.50   │ ← 只有一行，整条棕石色
 └──────────┴────┘               └──────────────────┘   王国名退到第二行小字
   └ 蓝签 = 我的王国等级            └ 不出现裸数字；"冒险者"三个字必须在场
 ┌──────────┐
 │ 💰 3 袋   │ ← 有进贡可收时才出现（M-7）
 └──────────┘
```
信息优先级：锁态节点的主角是**门槛**（🔒 冒险者 Lv.50），王国名是注脚；解锁节点的主角是**王国名 + 可收贡提示**，等级是注脚。裸数字「50」在任何情况下都不允许单独出现在徽章里。

#### P0 · M-3 顶栏钱包实时同步
把 `refreshWallet()` / `refreshPlayer()` 提到 `ShellCtx` 上（例如 `ctx.refreshChrome()`），凡是屏内发生网关写操作就调一次；地图侧在 `afterMutation()` 末尾调用。配套：升级/收贡成功时在顶栏对应货币上做一次 **+N / −N 飘字**，让"钱变了"在玩家视线落点（按钮附近 → 顶栏）之间有连线。

#### P0 · M-4 进贡口径收口为一个字段
`chip 文案`、`弹层库存`、`收取按钮可用性` 三处必须读同一个判据：**可实际入账的产出量**（gold/souls/keys 任一 > 0），而不是"累计小时数"。文案同步改：

```
底部 chip：  💰 进贡可收 · 4 国        （无可收时：进贡累积中 · 下一袋 14:20）
弹层库存：   黄金 1,240 / 灵魂 45 / 钥匙 0     ← 直接给数字，不给"袋"
弹层按钮：   收取进贡（黄金 1,240 · 灵魂 45）  ← 按钮上就写清收多少
满溢警告：   ⚠ 已满 12 小时，正在溢出          ← 达到 capHours 时出现，红棕色
```

### 五问自查

1. **3 秒问题**：不过关。三秒内我能看出"这是一张世界地图"，看不出"下一步点哪"。全屏视觉最强的是顶栏钱包与两列金色菱形，而菱形里 5/7 是死的（M-1）；唯一真入口（点节点开弹层）没有任何提示，破碎尖塔外圈那道呼吸光读起来像"镜头当前中心"而不是"点我"。新档更糟：41 个灰盾里那唯一一个彩色的盾，没有任何文案告诉你它是起点（`map-newsave-default.png`）。
2. **信息主次**：主次颠倒。玩家此刻真正关心的是「哪能打」「哪有东西收」「我卡在哪」——这三件事分别是：看不出（M-1/M-2）、看不出（M-7）、看不出（M-6）。而被排得最响的是 5 种货币余额（顶栏 1/3 宽）和 7 个静态入口。唯一的待领提示（进贡）是全屏最小的一枚 chip，还写错了词（M-4）。
3. **视觉语言**：一半一半。框体/菱形/纹章/衬线数字这套暗金体系是成立的，也和卡面同源；但**底图是写实航拍照**（M-8），和框内所有元素不是一个世界；徽章的蓝底等级签（`#4a7eae→#1a4568`）是全屏唯一的冷蓝，既不属于暗金体系也不承担语义区分（M-2）；右下角的锁图标是纯噪声（M-12）。
4. **操作路径**：核心路径「进地图 → 点王国 → 打任务」是 3 步且能走通。但周边全是断头路：5 个 rail 按钮点了无反应（M-1）；想找特定王国无检索只能盲拖（M-6）；想知道哪国有贡要一个个点开（M-7）；点了钱包按钮才能看到 12 小时上限规则（M-10）。
5. **极端态**：逐条实跑过——
 - **新档（Lv.1）**：41/42 锁定，地图看上去"整张都是死的"；顶栏荣耀 0；入侵 rail 变灰但幅度极小，点了给 toast「入侵需要主角 10 级（当前 Lv.1）」，文案是清楚的（`map-newsave-invasion-locked.png`）。
 - **未解锁节点**：纹章去色 + 棕签，去色做得够彻底；但签上的数字语义错（M-2）。
 - **进贡为空**：chip 变「进贡暂无可领」（`refreshDaily` `:314`），文案正确；但同一时刻弹层可能显示「已领取」而 chip 显示「已满」，两者不同步（M-4）。
 - **余额不足**：新档 2,000 金点「投入升级 · 1,000」**直接成功**了（`[新档点升级]` toast「提升至 2 级」），没有"你确定要在开局花掉一半家当吗"的拦一下（详见 `02-kingdom-sheet.md` K-1）；真正余额不足的分支走 `gateway.upgradeKingdomLevel` 的 `isFailure` → toast，没在地图上验到，属于设计过的（`mapScreen.ts:388-390`）。
 - **满级王国**：`mapScreen.ts:359-366` 有「已达满级 / 加成已对全体部队生效」分支并隐藏价签，这一态是设计过的。
 - **进贡溢出（>12 小时）**：**没有任何表现**，静默丢失（M-10）。
