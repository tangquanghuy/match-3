### 重设计提案

#### P0 · K-1/K-2/K-6 右栏重排（线框）
根本问题是**经济操作占了行动位**。右栏改为「三段式：我在哪 → 我该打哪 → 顺手拿/长线养」，主行动按钮唯一且是战斗：

```
┌────────────────────────────────┬──────────────────────────────────────────────┐
│                                │ KINGDOM OVERVIEW                        [×]  │
│                                │ 破碎尖塔          Lv.3/10   🔒 已解锁        │
│      立绘（430px，保留）       │ 古尖塔自裂隙中重生…（两行封顶）              │
│                                │                                              │
│   BROKEN SPIRE                 │ ── 我该打哪 ────────────────────────────────  │
│   破碎尖塔                     │ ┌──────────────────────────────────────────┐ │
│                                │ │ ⚔  王国任务 · 第 4 章          [ 出战 ]  │ │← 唯一 primary
│                                │ │    3/8 ●●●○○○○○  掉落：钢锭·蓝特质石     │ │  金绿底，含进度与掉落
│                                │ └──────────────────────────────────────────┘ │
│                                │ ┌────────────────────┬─────────────────────┐ │
│                                │ │ 🧭 探索（8/8 后开放）│ 📖 王国部队 3/47   │ │← 次级，各带明确落点
│                                │ │    重复刷材料       │    查看这 47 张 →   │ │  点了真跳转带筛选
│                                │ └────────────────────┴─────────────────────┘ │
│                                │                                              │
│                                │ ── 顺手拿 ──────────────────────────────────  │
│                                │ 💰 进贡已满：黄金 1,240 · 灵魂 45  [ 收取 ] │← 金色强调，写清数额
│                                │    ⚠ 已累积 12 小时，正在溢出                │
│                                │                                              │
│                                │ ── 长线养 ──────────────────────────────────  │
│                                │ 王国等级 3/10  ▓▓▓░░░░░░░                    │
│                                │ 满级奖励：全体部队 生命 +1                   │
│                                │ [ 投入升级 · 🪙3,500 ]  ← secondary，不抢主位│
└────────────────────────────────┴──────────────────────────────────────────────┘
```
信息优先级：**当前该打的那一关 > 可收的进贡 > 长线升级**。
主行动按钮位置：「我该打哪」段落内的「出战」，全弹层唯一 primary，颜色最亮、面积最大。
升级降为 secondary 并明确标注"满级才兑现"，避免新手把它当主线。

#### P0 · K-3 锁定态改成单一答案的"门禁屏"（线框）
锁定时不要把已解锁的版式打满破折号，直接换一套专用布局，全屏只回答一个问题：

```
┌────────────────────────────────┬──────────────────────────────────────────────┐
│      立绘（去色 + 压暗）       │ 🔒 尚未解锁                             [×]  │
│                                │ 荆棘森林                                     │
│        ╭──────────╮            │                                              │
│        │   🔒     │            │ 需要 冒险者 Lv.13   （你现在 Lv.12，还差 1） │← 唯一主信息
│        ╰──────────╯            │                                              │
│                                │ 解锁后可获得：                               │
│   THORNWOOD                    │  · 8 章王国任务与探索                        │
│   荆棘森林                     │  · 8 名部队（含 2 名史诗）                   │
│                                │  · 满级加成：全体护甲 +1                     │
│                                │                                              │
│                                │ [ 去打一场升级 → ]  ← 主行动，指回当前可打的│
└────────────────────────────────┴──────────────────────────────────────────────┘
```
要点：锁定态**不展示** kv-grid / 升级块 / 进贡行 / 三张入口卡（现在这些全在，只是填了破折号）；
把"解锁后能拿到什么"作为诱因展示（数据 `kingdomTroopPool` / `kingdomBonusStat` 已有）；
主行动是"回到我现在打得动的地方"，不给死路。

### 五问自查

1. **3 秒问题**：不过关。三秒内我知道这是"某个王国的详情"，但下一步会点错——视觉最强的绿按钮是花钱升级，不是开打（K-1）。真正的战斗入口在右下角一张灰卡里，和一个断头路按钮（K-2）长得一模一样。
2. **信息主次**：颠倒。玩家点开王国只为回答一件事——「我现在在这儿该干什么」。这件事的答案（任务 3/8，下一关是第 4 关）被压成一行 12px 小字；而"Lv.10 → 生命 +1"这种要 7 级之后才生效的注脚，被排进 kv-grid 用 22px Georgia 大字呈现（`style.css:.kv-grid b`）。
3. **视觉语言**：左栏立绘 + 金线内框 + 衬线标题这套做得好，是全项目里最成立的一块。右栏掉链子：三张 entry 卡是纯灰渐变盒子（`#2a2431→#1a1722`），没有稀有度框/纹章/图标语言；升级进度条紫色与顶栏经验条撞色（K-8）；`bag` 图标在小尺寸下读成锁（K-5）。这正是用户说的"各种方框按钮不美观"在本页的具体形态。
4. **操作路径**：升级 1 步、收贡 1 步、进任务 2 步（点卡 → 直接开打），路径本身不长。但有两条断头路：「王国部队」只给 toast（K-2）；锁定态的「王国部队」卡看起来能点实际也只给 toast（K-3）。另外"看不到点不着"的情况在锁定态成立——`bonus` 显示 Lv.10 加成却没有任何途径去拿。
5. **极端态**：逐条实跑过——
 - **锁定**：有专门分支但做成了"打满破折号的已解锁版式"，且 bonus 漏了遮罩、explore 文案口径不一、troops 卡漏了 `.locked`（K-3）。
 - **任务 8/8 全通**：`questProgress` 显示「8 / 8」，`exploreState` 变「已开放 · 重复刷取」，点任务卡给 toast「任务链已 8/8 通关，去探索模式重复刷取材料」（`mapScreen.ts:481`）——逻辑设计过了，但玩家要点了才知道，卡面上没有引导（K-10）。
 - **满级（Lv.10）**：`upgradeLabel` → 「已达满级」、`upgradeHint` → 「加成已对全体部队生效」、价签隐藏、按钮禁用（`:359-366`）。这一态是设计过的，是全弹层处理最完整的极端态。
 - **进贡为空**：库存「已领取」+ 按钮禁用（实测 `collectDisabled:true`）；但缺"下次几点满"（K-4）。
 - **进贡有小时数但 0 命中**：库存显示「0 袋」、按钮**仍可点**、点了得到「暂无可领取的进贡」——新档必然遇到（见 `01-map.md` M-4）。
 - **余额不足**：走网关 `isFailure` → toast（`mapScreen.ts:388-390`），设计过；但反过来"余额够但不该花"这一态完全没防护——新档 2,000 金一点就扣 1,000（K-1）。
