## 3. 部队编成 `#team`
> 计数：P0 4 / P1 6 / P2 1

走查方式：Playwright 无头 chromium，视口 1600×900。一条完整的**编队动线**跑到底——
进页 → 读常态（先锋队 4 人 · 出战中）→ 名册翻页（1/11 → 4/11）→ 搜索（中文名 / 试着按魔法色搜）→
种族 tab 筛选 → 点选 4 号槽 → 单击看详情坞 → 双击编入（撞"已在编队中"）→ 打开旗帜选择器（滚到锁定区）→
双击移除到 2 人 → 点保存撞校验 → 队伍管理菜单 → 清空成员到 0 人 → 撞"新建受阻" → 撞"删除当前出战队受阻"。
脚本：`artifacts/ux-audit-scripts/u2-team.mjs`。探针原始数据：`artifacts/ux-audit-scripts/u2-team-report.json`（含配色取样与布局实测尺寸）。
console 错误 **0 条**。UX-11（「过于沉闷单调」）在本页可以量化，见 TM-4。

### 五问自查

1. **3 秒问题**：**半过关**。三秒内能看出"这是编队页、左边是我的队、右边是可选成员"——两栏分工是清楚的，`team-01` 一眼就懂。不过关的是"下一步该点哪"：页面上没有任何一个强 CTA。唯一的实底按钮「保存更改」在常态下是 `#191720` 的近黑灰（`screens.css:714-718`），比旁边的「旗帜：破碎尖塔」还弱；而视觉上最跳的是右上角那枚绿色「出战中」徽章——它是一个**状态标签**，不是可操作项（`screens.css:675`）。结果是玩家的眼睛被一个不能点的东西吸住，真正该点的"选槽位"是四个长得一模一样的灰框。

2. **信息主次**：**颠倒**。玩家此刻要做的判断是"这支队够不够强""缺哪种颜色""谁该上 1 号位"。这三件事需要的数据——四维、法力色覆盖、耗蓝——在左栏一个都没有（TM-1），全被塞进右栏底部那条一次只显示一张卡的详情坞（`布局尺寸.inspect 852×200`）。反过来被排得最响的是注脚：四张 296×238 的立绘（占满左栏 622px 高度的绝大部分，却只承载两行字）、顶部 1544×62 只装一个 tab 的切换条（TM-11）、以及「出战中」这个重复了两遍的状态词。

3. **视觉语言**：**与全局体系同源，但内部零层级**——这就是 UX-11「过于沉闷单调」的机制。暗金底 + 衬线标题 + 卡面立绘都对得上全局；问题是**七类容器用了同一档**：`panel #0c0c14` / `slot #101018` / `mini #0b0b12` / `slot.empty` 条纹 `#12121a-#16161f`，描边全是 `#e6d09d` 家族的 1px 细线（探针 `面板配色取样` 实测）。没有一处用面积、明度或质感区分主次，于是整屏读起来像一张没有排版过的表格。两个例外反而是问题：绿色「出战中」徽章与绿色「已上阵」角标是全页唯一饱和色，抢了 CTA 的视觉位；空槽位的 45° 条纹（`screens.css:686-689`）是全页唯一的纹理，把"什么都没有的格子"做成了最有细节的格子。

4. **操作路径**：**主路径 3 步能通，但每一步都有陷阱**。通的：点槽位 → 双击名册卡 → 点保存。陷阱：选中态看不出来所以经常编错槽（TM-4）；双击槽位会静默删人（TM-3）；想换位无路可走（TM-2）；名册要翻 11 页且没有有效筛选（TM-6）；打开旗帜选择器后 Esc 和点空白都关不掉（TM-5）；主角的「图鉴」按钮直接开新浏览器标签（TM-11）。断头路两条：**没有"一键推荐/上次使用/复制队伍"任何快捷方式**；**没有从这里直接出战的入口**——保存完要自己走回地图。

5. **极端态**：逐条实跑过——
   - **2 人（不足）**：保存按钮仍可点（探针 `2 人队时保存按钮 { disabled: false }`），点了给一条即消的 toast，面板内无常驻提示（TM-8）。`setActive` 这一侧倒是设计过：`teamScreen.ts:372-373` 会 disable 并写 `title="至少编入 3 名成员"`，徽章也会切到 `incomplete` 红棕色（`screens.css:676`）——同一条规则在两个按钮上一个拦一个不拦。
   - **0 人（全空）**：不崩，但徽章仍写「出战中」（TM-9）。空槽文案「空位 / 点选作为编入目标」是写过的，但 1 号位的 💀 标记在空态下消失（`teamScreen.ts:417-422` 的 empty 分支没有 skull），于是"队首吃骷髅"这条规则在最需要提示的时候（正要从零编队）反而不见了。
   - **旗帜未解锁**：设计过——`disabled` + `opacity .45` + 「任务 8/8 解锁」文案，系统层还有 `bannerEquipIssue` 兜底（`teamRules.ts:82-85`）。但 40 项混排在 3 项可用的里面（TM-5），设计过的是"单项表现"，没设计的是"40:3 这个比例下怎么让人找到能用的"。
   - **重复编入**：设计过——`assignInspected` 先查 `this.slots.includes(value)` 并给 toast「法露特 已在编队中。」（`teamScreen.ts:491-494`），探针 `双击编入后 toast` 实测到这句。
   - **删除当前出战队**：有拦截（`teamScreen.ts:621-623`「出战中的队伍不能删除。」），但空队态下玩家先撞到的是 `addTeam` 的那句错文案（TM-10）。
   - **只有 1 支队**：`renderTeamTabs` 正常渲染单 tab，`deleteTeam` 被出战拦截挡住 → 不会出现"删到 0 支队"的破态。这一条是设计过的。
   - **主角未装备武器**：设计过且做得细——`teamScreen.ts:322-326` 给出「主角法术（未装备武器）」+「尚未装备武器：去英雄页的武器库装备一把，武器决定法术、法力色与耗蓝。」，是本页写得最好的一段极端态文案（可惜没给跳转按钮）。
