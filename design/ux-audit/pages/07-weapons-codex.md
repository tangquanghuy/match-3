维度取舍（原六行 72 枚 → 六枚下拉 + 汇总条，顶部占高从 240px 压到 ~76px）：

| 维度 | 处置 | 理由（含盘点数据） |
|---|---|---|
| 稀有度（7） | **保留**，下拉多选 | 玩家最主要的筛法；基数 Epic 421 / UltraRare 93 / Mythic 77 / Doomed 76 / Rare 28 / Uncommon 15 / Common 8 —— 每档都值得单独筛 |
| 类型（14） | **保留**，下拉多选 | 基数 19~96 分布均匀；与天赋条件（`selfStatIfWeapon` 按 weaponType 判定）直接相关，是真决策维度 |

### 五问自查

1. **3 秒问题**：不过关。三秒内我看到的是"一片彩色武器缩略图 + 一堵药丸墙"，能看出这是某种列表，看不出它属于哪个游戏（C-1）、也看不出该先点哪。全页视觉最强的是 718 张满饱和立绘（面积占 73%），第二强的是 72 枚筛选 chip；唯一的主行动（搜索）是个 200px 的灰框，排在标题右边最不起眼的位置。
2. **信息主次**：颠倒得很彻底。玩家关心「我有没有 / 我能不能用 / 我怎么拿到」——三件事页面**一个都没回答**（C-4）。被排得最响的反而是开发口径：标题栏「战斗可用 710 · 完整实现 683」，以及在 718 张卡上重复 683 次的「完整实现」（C-5）。
3. **视觉语言**：与全局体系**完全不同源**。字体是 Playfair/Noto Serif（外壳也用，这点一致），但框体、底色、chip、按钮全是另一套扁平灰蓝（`#16161f / #3a3f4b / #12121c`），没有暗金描边、没有卡面框、没有菱形徽标、没有衬线数字的处理。稀有度还被编码两次且两套颜色冲突（C-6）。
4. **操作路径**：进来 1 步（点按钮开新标签），**回去 0 步**（没有返回控件，C-1）。筛选要在 72 枚 chip 里找目标、筛空了无法一键恢复（C-2）。看到喜欢的武器之后，路径**断在这里**：没有"去锻造"、没有"装备"、没有"哪里能拿"（C-4）。
5. **极端态**：逐条实跑——
 - **0 结果**：纯黑屏，无文案无恢复（C-2，`codex-filter-empty.png`）。
 - **搜索无命中**：同上，而且是最容易触发的一类（搜效果词必 0，C-3）。
 - **占位武器（mana-only，8 把）**：照常展示、照常可点、详情里只用绿/黄/灰三色小字标「占位」，**不说"永远不可装备"**（C-4）；其中两把连名字都还是英文（C-10）。
 - **部分实现（partial，27 把）**：详情里会列出「未实现子句（N）」逐条展示被跳过的法术文本——这是把管线日志直接给玩家看。
 - **滚到底（第 21 屏）**：网格结束，右侧详情面板仍钉在顶部显示第一张卡，下方 700px 空白（C-8）。
 - **图片加载失败**：卡面有 `onerror="this.style.visibility='hidden'"`（`:154`）→ 图直接消失留白框，无占位符；不过实测 `imageFile 缺失 0 把 / 指向不存在 0 把`（`u3-catalog-audit.txt`），这一态当前不会触发。
