# 武器淬炼 + 熔炉锻造 · 机制设计与页面方案

> 2026-09-19。考据来源：官方论坛（Discourse 原帖引用见文末）、官方解锁等级表（topic 89373）、
> 熔炉规则官方帖（topic 55952，2026-09-17 已入库 GOW-WEAPONS 调研）。数值除注明「官方原文」外
> 均为**本项目设计值**（标注可调），不声称官方数值。

## 0. 官方武器获取/成长四通道（考据结论）

| 通道 | 官方规则 | 我们的对应 |
|---|---|---|
| **淬炼 Tempering** | 玩家 3 级解锁；用**与武器稀有度对应的钢锭**升级武器；每级提升武器属性；词缀随等级解锁、在主效果之后触发；Doomed/Cursebreaker 武器改用**彩色熔铸符卷**；锻造宝珠可跳级/直接满级 | 保留全部结构，数值自定（见 §2） |
| **熔炉 Soulforge** | 玩家 38 级解锁 Tier 1-10（500 灵魂），45 级 Tier 11-20（50 诅咒符文）；可铸造**活动系武器**（入侵/突袭首领/末日之塔等）；精通/任务线武器与 $4.99 王国包武器**永不进熔炉**（官方帖原文） | 同规则；可造清单 = 数据文件配方表（白名单制） |
| **灵魂直购** | Dawnbringer：三色神话，130 万灵魂 | 同构：神话档高价直购位 |
| **王国武器包/活动商店** | $4.99 包随王国活动返场 | 对应我们的活动/抽卡产出，不在本设计内 |

## 1. 领域模型（纯逻辑，持久化归 save v2）

```
淬炼状态: weaponTempering: Record<weaponId, level>   // 缺省 0，上限 20
钢锭库存: ingots: Record<rarity, count>              // rarity ∈ 武器稀有度全集（含 Doomed）
熔铸符卷: forgeScrolls: number                       // Doomed/Cursebreaker 专属材料
配方表:   src/meta/data/soulforge.ts                 // 白名单：id → {灵魂, 钢锭档×数量, 符卷?, 上架档位}
```

接线点（一行级，归 J 的 v2/桥接）：
- `state/schema.ts`：MetaSave 增 `weaponTempering` / `ingots` / `forgeScrolls` 三字段（默认值零头）
- `battleBridge`：组队快照时把 `weaponTempering[equippedWeapon]` 写进主角 `Character.temperingLevel`
  （**引擎侧已就绪**：`tempering` 来源 kind 已按「+N/级 × 当前等级」参与法术数值，0 级=增项 0）

## 2. 淬炼数值（设计值）

- 等级 0~20；每级消耗：`对应稀有度钢锭 × ceil(level/2)` + `黄金 × 200×level`
- 稀有度钢锭基数（每级 1 起步的手感档）：Common 2 / Uncommon 4 / Rare 8 / UltraRare 16 /
  Epic 32 / Legendary 64 / Mythic 100 / Doomed 100（且每级另需 1 熔铸符卷）
- **属性成长**：每 2 级主角装备加成 +1（攻击/护甲/生命/魔法轮流），由战斗桥按
  `floor(level/2)` 叠加进主角面板——不改武器法术公式
- **词缀解锁**：普通武器 5/10/15/20 级解锁 `affixes[0..3]`；Doomed（5 词缀）4/8/12/16/20
- 词缀战斗语义（官方：主效果之后触发）**二期**接线；一期词缀仅解锁展示

## 3. 熔炉数值（设计值）

- 配方白名单首批（对齐官方「活动系可造」口径，从 718 目录选 10 把）：
  事件武器系 ×6（Eggsplosion / Eye of Xathenos / Fire and Ice / Slay Bells / Withering Touch /
  Spark Rocket 2.0.16——官方目录里无王国包归属的活动武器）+ 神话直购位 ×1（Dawnbringer，130 万灵魂）
  + Doomed 样例 ×2（末日魔典/在劫难逃的匕首：灵魂+神话钢锭+符卷 25）
- 配方消耗结构：`灵魂（5k~1300k 按稀有度阶梯） + 对应稀有度钢锭（10~100） + 诅咒符文（Tier11+ 档位）`
- 解锁档位：Tier1（玩家 20 级，对齐我们主角等级体系）/ Tier2（40 级，可造神话/末日档）

交互要点：淬炼按钮长按连点防抖、材料不足置灰并列缺口、词缀解锁瞬间播放特效、
熔炉配方按解锁档位遮罩（未达标显示「主角 40 级解锁」）。
