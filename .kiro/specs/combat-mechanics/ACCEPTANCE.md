## 规模化人工验收方案（回应「一千多种技能不可能手动组合」）

**原则：机器全量兜底 + 机器批量产出人工抽查物料，人工只做「看图挑错」，不做「逐个组装」。**

1. **技能放映厅（Skill Theater，建议下一批做）**：给测试台加批量驱动——按固定种子逐条装配 521（后续 555）条已编译技能：自动布盘 → 充能 → 施放 → 截盘面/事件流 → 产出一张 HTML 画廊（每条技能：官方描述原文 vs 实际事件流 + 前后对比截图）。人只翻画廊标记异常。估算 2~4 秒/条，全量 20~35 分钟可挂机跑完。所需调试钩子已存在（setDebugSkill / debugSetGems / 固定种子），缺一个 runner + 画廊生成器（可参考既有 mobile-acceptance-shots.mjs 的截图脚本先例）。
2. **千场烟雾（敌人侧）**：AIRP 分拣引擎已能按 tier+种族确定性编配敌人——补一个无头脚本：批量生成 N 千场种子对局（双方都由分拣引擎编配），断言不崩溃、终局可达、事件流合法。覆盖「敌人也是不可能手搓」的问题，纯引擎层、无需浏览器。
3. **敌人图鉴**：按 tier × 种族枚举分拣结果，输出编配快照（技能/特质清单）成页，人工核对的是「编配策略」而不是每个敌人。
4. **分级验收制度**：P0 = 自动化门槛（lint/test/build + 审计套件 + 覆盖对账，已全绿）；P1 = 放映厅/图鉴翻阅（挑错）；P2 = 仅对 P1 标记项与新机制做深度人工核对（本轮 B 的 10+5 抽样即 P2 样板）。
