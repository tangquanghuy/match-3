# 特殊宝石 · 语义与美术需求单（2026-09-14）

语义均核对自官方公告/官方论坛（来源链接见文末），非推断。
热度数据来自 `artifacts/gap-analysis.txt`（技能提及条数 + 特质出场次数）。

---

## 1. 末日骷髅 / 厄运骷髅（Doomskull）🔥 热度第一

- **语义**：被匹配时 = 普通骷髅伤害 **+5 点额外伤害**，并**引爆周围一圈宝石**（连锁照常结算）。不走法力。
- **变体**：至尊末日骷髅（Uber Doomskull，中文数据里作"极度末日骷髅"）——更强版本，仅由特定兵种/武器生成。中文数据里"末日骷髅/厄运头骨"是同族不同译名，实现时按同一种处理。
- **引用**：42 条技能 + 5 特质 code。代表作：「坟墓之斧」把全盘骷髅转成末日骷髅；「祖先的召唤」直接创造 7 颗。
- **外观方向**：紫黑色骷髅头，眼窝透紫光，比普通骷髅更大更狰狞，待机有脉动/呼吸感。至尊版：更大、加深色尖刺与更强红紫光效。
- **美术清单**：本体（待机态 + 高亮态）、匹配引爆特效（紫黑爆裂）、（可选）至尊版一套。

## 2. 炸弹宝石（Bomb Gem）🔥 热度第二

- **语义**：被**摧毁**时（注意：不是被匹配——三消不会触发它，只有爆破/爆炸类效果能点燃）爆炸，摧毁周围一大圈宝石。
- **引用**：16 条技能 + 3 特质 code（"核心不稳"26 个兵种：死亡时留下 3 颗炸弹）。
- **外观方向**：黑色圆炸弹 + 点燃引信，引信火花待机动画。
- **美术清单**：本体（待机 + 高亮）、爆炸特效（橙红大爆炸）。

## 3. 织网宝石（Web Gem）✅ 状态语义已实现（2026-09-14）

- **语义**：紫色宝石。被匹配时，对**一名随机敌人**施加"织网"状态——**魔力降为 0，每回合累计 10% 几率挣脱**。
- ✅ **引擎已对齐**：web 是独立状态（`status.ts` 的 `WEB_STATUS_ID`），与缠绕（entangle=攻击归零）拆分。实现点：`casterMagic()` 技能数值归零、`buffOne()`/`grantStat()` 拦截魔法增益、`tickStatuses()` 挣脱判定（TurnEngine 传入种子化 rng）。特质表已重生成：slippery/darkancestry（免疫）、snare（命中附网）、stalker（屠戮）4 个 code 从 entangle 翻正为 web。
- **宝石本体（棋盘上的紫色蛛网宝石 + "被匹配→随机敌人施网"行为）尚未实现**，属于特殊宝石批次；等美术素材。
- **引用**：8 条技能 + 2 特质 code（spidersilk 14 次）；另有一批"织网状态"类技能已可承接。
- **外观方向**：紫色调蛛网图案，圆形网结+丝线质感，半透明底。
- **美术清单**：本体（待机 + 高亮）、匹配特效（蛛丝散开）、Web 状态图标（✅ 已有代码绘制的 SVG 徽章，见 `src/render/statusBadges.ts`）。

## 4. 幽魂宝石（Ghost Gem）

- **语义**：被摧毁时，摧毁者获得 **10 灵魂**（Souls）。
- ⚠️ **语义冲突**：灵魂是战斗外货币，已裁定不做——**原版语义在本作里没有战斗效果**。它在本作的引用价值主要是作为技能数值的计数燃料（「遗忘刃」"数量因鬼魂宝石数量而增强"）。
- **建议**：改语义（如"摧毁者获得法力/算作任意色计分"）或排最低优先级。**美术可以最后再做**。
- **引用**：8 条技能 + 2 特质 code。
- **外观方向**：半透明幽蓝白色幽灵脸，雾状拖尾。

## 5. 通配宝石 x2/x4（Wildcard Gem）

- **语义**：可与**任意颜色**组成三消（只走直线），宝石上的数字是**法力收益倍率**（x2 翻倍、x4 四倍；多个通配同次匹配倍率相乘）。
- **引用**：5 条技能 + 2 特质 code（wildtribe/wildmagic）。
- **外观方向**：棱镜/彩虹色星星或钻石，中央醒目的 x2 / x4 数字。
- **美术清单**：x2、x4 两版本体（待机 + 高亮）、匹配特效（彩虹闪光）。

## 6. 许愿宝石（Wish Gem）

- **语义**：**无法被匹配**（三消拿它没办法），只能被爆破/摧毁类效果触发。触发时 5 选 1 随机：己方 1/2/3/全员回满法力，或**双方全员回满法力**（约 20% 几率的坑）。
- **引用**：2 条技能 + 3 特质 code。
- **外观方向**：金色神灯或星光漩涡，梦幻华丽风。
- **美术清单**：本体（待机 + 高亮）、触发特效（金光喷发）。

## 7. 闪电宝石（Lightning Gem）—— 两种变体

- **语义**：被匹配**或**被摧毁时，清空整行/整列。
  - **黄色闪电**（竖向闪电形）→ 清空整**列**
  - **蓝色闪电**（横向闪电形）→ 清空整**行**
- **引用**：9 条技能 + 1 特质 code（几乎全是塔罗牌系列「抽到XX」）。
- **外观方向**：锯齿闪电形状，黄版竖向、蓝版横向——**方向即语义，形状必须能一眼区分**。
- **美术清单**：黄/蓝两版本体（待机 + 高亮）、触发特效（电弧扫过整行/列）。

## 8. 沙漏宝石（Hourglass Gem）

- **语义**：黄色沙漏。被匹配时获得**一次额外回合**。
- **引用**：5 条技能 + 2 特质 code（塔罗牌系列为主）。
- **外观方向**：金黄色沙漏，沙粒缓缓流动感。
- **美术清单**：本体（待机 + 高亮）、匹配特效（时间光环）。

## 汇总：给美术的打包建议

| 优先级 | 宝石 | 理由 |
|---|---|---|
| 第一批 | 末日骷髅、炸弹 | 热度断层领先（47/44 vs 23 以下），玩法冲击力最大 |
| 第二批 | 闪电、通配、织网 | 规则简单/引用扎实；织网需要连带一个新状态图标 |
| 缓做 | 许愿、沙漏 | 热度低，集中在塔罗系列兵种 |
| 建议重定语义 | 幽魂 | 原版给灵魂（战斗外货币），本作无战斗效果 |

**每颗宝石的标准物料**：本体贴图 ×2（待机态、可消除高亮态）+ 消除特效一段 +（织网另需）状态小图标。棋盘逻辑格 40px、渲染 DPR 封顶 2，建议出图按 128×128（2x 冗余）交付，格式与现有 `src/assets/fx/*_strip.png` 序列帧约定一致。
